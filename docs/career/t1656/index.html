📘 我愛客戶之 基本構成

關於老闆的主題，我一共寫了十篇，雖然還有不少網友提供了關於他家老闆的有趣故事…

✍ Tiger&蘋果爸 · 2009-01-19

關於老闆的主題，我一共寫了十篇，雖然還有不少網友提供了關於他家老闆的有趣故事，但還是想暫時在這兒打住，先換換別的主題，過些時候再回來續談老闆。

那接下來聊什麼呢？客戶吧。

客戶是另一種奇妙的族類，雖然他們的智力和老闆約在伯仲之間，但他們的權力大於你的老闆、財力大於你的老闆，所以客戶是有能力〝代替月亮懲罰你老闆〞的人。因此連老闆都必須俯伏在他的腳前獻上敬拜和讚美，那我們這些小嘍囉豈有在他面前撒野的份？所以接下來幾週，我就來分享一些這幾年來我面對客戶的一些小小心得，也歡迎大家一起參與討論。

首先我恭敬的繪製一幅客戶的玉照，並配上文字，這樣可以幫助大家在最短的時間內稍稍明白偉大客戶的基本構成，其他的等我把欠大家的卡片寫完再來聊.... >__<
