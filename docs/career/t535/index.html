轉職該不該？及抽身的美學

轉職該不該？及抽身的美學

換工作以後會更快樂嗎？…

人由於學習、接觸新事物，產生興趣後，往往希望追求「新領域的突破」，於是「轉職」就成為必然的解決方法。這些成功者之所以能成人所不能成者，必須具有實力，以及善於把握機會…

文-邱文仁

一生能有幾次工作？

根據不久以前的一個統計顯示，台灣每一百個上班族中，就有「五十一個」心裡有轉職的念頭，隨時打算換工作！尤其是每年到了農曆春節前後，就是我們所謂的「轉職季」，上班族總會來個大搬風。然而，換工作以後會更快樂嗎？恐怕沒有人可以事先確定。

換工作到底好不好？其實沒有標準答案。我認為，即使在景氣最好的時代，生涯規劃也並非「一生只有一次選擇」，每個人一生中，或多或少會修正自己的生涯之路，這是無可厚非的現象。

如果一個人在很年輕的時候，就找到興趣所在，並投注一生的心力成為這方面的專才，幸運的，又未曾經歷什麼不可抗拒的變數，已經是非常少數的現象了。然而，隨著時代的變遷，科技的發達，上班族難免遇到產業的外移、公司的變革、甚至職務的消失等狀況，即使不想轉換跑道，上班族也不一定可以如願以償。

特別是，人由於學習、接觸新事物，產生興趣後，往往希望能追求「新領域的突破」，這時候，如果既有的工作無法滿足這種新的追求，「轉職」就成為一個必然的解決方法。大多數在職場上卓然有成的人，其實都沒有從一而終的在一個位子上待一輩子，那些成功人士往往因為某一個突發事件，繼而追求另一個生涯目標。但是這些企業家之所以能成人所不可成者，必須具有實力，以及善於把握機會。「實力」往往來自於之前的努力及磨練，甚至是來自於曾經經歷不同環境的洗禮；而「機會」則是靠自己創造，以及由於多看而產生的觀察力。

如果要分析換工作的原因，我認為不脫以下幾種：

1. 非自願性質的轉職

台灣人一向愛換工作，過去景氣好的時代，最常因為追求高所得而跳槽。過去的台灣上班族，往往薪水哪裡好就往哪裡鑽。不過，這一兩年來景氣差，許多上班族因為遇到公司的裁員，合併，或公司倒閉等因素，不得不轉職。甚至，是已經預期所處企業即將發生的狀況，先一步準備退路。

建議：

如果是遇到這種非自願的因素，之前必定已有預警！我建議上班族平日就要多關心公司營運狀況及策略方向，以及隨時增加自己的職場競爭力，讓自己成為搶手人才。如果自己實力夠強，就不必過於擔心劇烈的職場變化會給自己帶來極大的負面影響。

2. 工作內容的變化或不合理

隨著整體經濟環境的惡化，許多上班族也退而求其次，只要求一個穩定的公司，然而，也未必可以達成願望。因為不景氣中，企業會不斷的調整目標，及賦予員工更多的要求及職責！這時，工作內容往往會和原先的職務內容不符合。即使是很積極的上班族，也可能因為不合理的工作內容而萌生去意。例如，不合理的超時工作，不合理的業績目標，沒有支援的工作等等。

建議：

企業中個人工作內容的調整，是不景氣時最常發生的事情！尤其是大部分的企業，傾向以「遇缺不補」的方式來節省人事的開支，這時候，分擔離職同事的工作，是很常見的現象！不必埋怨及驚訝！除非工作的份量太不合理，或是離自己的專長太遠，建議上班族要學習適應不同的職責，抓住舞台好好表現，讓自己成為組織中不可或缺的人才！

3. 感覺自己在組織中沒有發展

如果工作無法將個人的優點發揮，許多人會產生不滿足的感覺；而公司沒有適時的給予肯定及尊重，也會讓「求成取向高」的上班族心生不滿。或者，升遷管道不暢通，階層太多，感覺公司格局太小，和未來生涯發展不能吻合等等，都會讓上班族萌生去意。

建議：

如果要找尋有發展的職務，必須從了解自己開始。建議上班族檢視自己的「能力、學歷、經歷」，然後在求職網站中搜尋符合自己專長的工作，之後，撰寫能夠有效呈現優點的履歷表，主動投遞，努力爭取符合志趣的工作。

4. 工作環境人際氣氛差：

無論多理智，人終究是感覺的動物，辦公室氣氛惡劣，是員工跳槽的重要原因之一。許多公司在成立初期雖然規模小、資源少，但是大家反而同舟共濟、互相體諒；等到公司規模變大，人反而變得自私起來。工作環境人際爾虞我詐，其實比繁重的工作更令人討厭，因此是員工離職的重要原因之一。

建議：

工作環境的氣氛和人際問題哪裡都有，只是程度大小而已。如果因為這個原因轉職，也要考慮下一家公司也有可能有同樣的問題，所以還是要調適自己擁有適應環境的能力才是。建議上班族不要把注意力放在人際的問題上，盡量找尋工作中其他的意義及價值。

5. 和上司不合

和上司不合，可能純粹是對工作的看法不同，或是遇見一個不好的上司也有可能。如果是對工作的看法不同，上班族要以開放的心態，和主管提出討論，並尊重上司的意見，不要輕易的離職。如果遇到的是所謂「不好的上司」：例如自私無能、剛愎自用、利用部屬、太過情緒化等等，因為上司和部屬的互動密切，部屬很有可能無法忍受而離職。

我的看法：

相較於以上兩種情形，上班族傾向於因為「工作環境人際氣氛差」離職的比例較多，這是因為如果遇到討厭的上司，員工會組成小圈圈，在心理上共同反抗上司，反而有「相互依存的同伴感情」，未必會因為上司的因素輕易離職，這是非常有趣的職場現象。

6. 錢的因素：

上班族流行一句話：「老闆不加薪，自己加」。的確，在某些行業，跳槽是最快速加薪的捷徑，例如流動率很高的廣告業，或是某些很搶手的技術人員。有些人則是喜歡隨波逐流，看到證券業年終獎金多，就一股腦往裡面擠；聽到「電子新貴」的名詞，就要往電子產業擠。這是景氣好時最重要的跳槽理由。

建議：

如果新工作挑戰性更高，薪水更多，跳槽是無可厚非的，不過有一得必有一失，跳槽過去也未必事事盡如人意。如果，上班族只是哪裡熱門就網哪裡鑽，等到鑽進去了，說不定產業榮景已經不在，只是白白浪費時間。

7.個人因素

個人因素有所謂搬家，生子，移民，甚或對工作厭煩想轉換跑道也算。

無論是什麼因素，我認為「轉職」不是情緒的發洩，也不是逃避的方式，更不是對原雇主的不忠誠。現在的觀念和老一輩的「一輩子從事一份工作」已經不一樣，反而，在年輕的時候就有轉職的經驗，會比年紀一大把了再考慮轉職更好。不過，過度頻繁的轉職，容易引起面試官的質疑。這時，轉職太頻繁的人也許可以考慮不要在履歷表上呈現「工作時期太短」的經歷。
