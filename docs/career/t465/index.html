📘 CAD只是個「工具」

看了以下文章有感而發，想要靠著CAD工具發光發熱並賺大錢，這真的不是一件簡單…

✍ Tiger&蘋果爸 · 2008-09-20

看了以下文章有感而發，想要靠著CAD工具發光發熱並賺大錢，這真的不是一件簡單的事，以前傳統的觀念是學習一技之長不怕沒飯吃，在現今社會中變的不再是那麼一回事了，你若是沒有專業知識只能稱作電腦繪圖人員(抄圖員)，而具備這樣能力的人滿街都是，因為學校及補習班都只是教你如何使用工具，並未教導你如何搭配專業知識，而忽略了業界實務需求，所以電腦只是一個輔助工具，最重要的是你的專業知識，如果你能做到判斷一個事件的輕重緩急，何時適當的正確使用工具滿足業界需求，甚至引領引導同事一起學習，相信你會越來越有價值!

--------------------------------------------------------------------------------------------------

最近到工廠，現場的人說：「我申請一台電腦，要開始學 AutoCAD，以後當設計，不用待在工廠。」

偶爾會聽到，這樣的抱怨：「做這個工作沒發展，我想先去學會電腦繪圖，以後改做設計的工作。」

你準備好當設計了嗎？學會AutoCAD就可以當設計嗎？

甚麼是CAD？是「Computer-Aided Design」的縮寫，是「電腦輔助設計」的意思。

所以，CAD只是個「工具」。

學會使用一種工具，和操作這個工具的技術，只會進入到另一種作業階層，換一種作業環境而已。

年前，公司新同事在職訓局學習過AutoCAD，指令操作功夫了得，甚至是3D繪圖指令也駕輕就熟。

年來，新同事工作上除了繪圖外，還是只能幫設計做繪圖的工作，當了稱職的電腦繪圖員。

雖然對AutoCAD的操作職能，遠遠凌駕於設計者，缺了設計的專業技能，CAD也只是個繪圖工具。

如果擁有一個創意腦袋，或者是對設計工作懷抱無限憧憬，才是成為設計人的途徑。

拜電腦科技之賜，設計者有了資訊化的工具，更精準的實現設計理想，更多元的呈現設計理念。

不是農夫的，給他一把鋤頭，除了把玩之外，是種不出一粒稻米的。

不適設計的，給他一台電腦，除了仿製之外，是做不出任何創作的。

想學CAD前！先想想，用CAD做甚麼吧？
