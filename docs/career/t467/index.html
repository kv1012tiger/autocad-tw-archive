📘 AutoCAD 新版本的差別

《評論》Auto CAD2007差別?

✍ Tiger&蘋果爸 · 2008-09-20

《評論》Auto CAD2007差別?

http://tw.knowledge.yahoo.com/question/article?qid=1707032203508

AutoCAD 在進行升版(升級)時，可分為功能與效能2個部份來說明，在業界實務應用上發生的問題，或是不足的地方會再進行修補或升級，甚至開發新功能來因應需求，因為以舊版本在當時已可滿足需求，而時代的不同需求也不同，所以升級是必要的也是趨勢主流。

AutoCAD 2007在功能上比較具代表性就是3D技術的全面升級，相信有使用過AutoCAD 2007的人一定會愛不釋手，因為真的是太神奇了，可以在短時間內針對實體模型快速編輯，整體3D運用在技術上是一個重大突破，打破以往AutoCAD的3D不行的觀念。而在2D指令功能上也有顯著的提昇，除非在職場上運用的層面較廣，必能使用到較多新功能。

以建築業與機械業為例，建築著重的是全面性的功能整合運用，從繪圖指令、編輯指令、文字、標註、線型、圖層、圖塊(工具選項板)、外部參考、出圖(配置出版)、圖紙集、電子傳送等等，所有指令功能環環相扣，在效能及效率可以大大提昇，即可提升職場競爭力。機械業的運用如CNC就比較著重於繪圖指令、編輯指令、圖塊等等，並不需要用到那麼多新功能，所以不同的領域族群對AutoCAD在進行升版(升級)時，抱持的兩極的看法，所以以各領域的需求，升級不會影響作圖的方式，但是攸關著整體效率及日後的圖面管哩，若想要在現在這各進步快速的社會站住腳，所以我想是有升級的必要。

當學習了 新版本 不用擔心在 舊版本 無法使用，因為基礎指令都一樣，差別在用舊版本畫圖可能要60分鐘，新版本可以不到50分鐘內完成，以我自己的學習經驗為例，以前出圖時一個專案二、三百張圖，往往會花上我一天的時間，而現在只需要30分鐘即可完成，而30分鐘式電腦出圖的時間，我只需要指定出圖清單大不了3分鐘的時間，這就是最明顯的差別。

而新版本也很貼心保留舊版本的系統變數設定，讓暫時還不習慣的人多一個選擇，回復成舊模式運作，版本規格在壓縮率也有大幅度的提昇，舊版本100張圖面檔案容量為50m，在AutoCAD 2007版本的檔案壓縮率可大幅度減少到20m左右，基礎指令運用也減少了多餘的步驟，如複製(COPY)指令已無需輸入M多重選項，而且還整合了Express Tools 指令功能，以 圖層II 工具列最具代表性，完完全全的在工作繪圖效率上證明了新版本的優勢。

最後與大家分享我的Autodesk Suscription名言換現金最佳金句徵選~

『新版本 新技術 新趨勢，新功能 新資源 新優勢。』

軟體日新月異發展的『新版本』，因應時代潮流創新的『新技術』，誰能掌握已成為一股『新趨勢』；

如何以正確觀念學習『新功能』，擅用此些陸續開發的『新資源』，則成為提升競爭力的『新優勢』。
