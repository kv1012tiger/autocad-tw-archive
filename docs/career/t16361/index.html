最近台日職場上掀起「半澤直樹」風潮，劇中的名言「部下的苦勞是上司的功績、上司…

✍ Tiger&蘋果爸 · 2013-09-26

最近台日職場上掀起「半澤直樹」風潮，劇中的名言「部下的苦勞是上司的功績、上司的過錯是部下的責任」，一語道盡上班族在工作職場上所面對的無奈；根據360d才庫人力資源所發布的「職場揹黑鍋調查」，近7成的受訪上班族有揹黑鍋的經驗(不是自己的錯誤，卻替別人扛責任)，個性太善良被公認是最容易揹黑鍋的人。

360d才庫人力資源「職場揹黑鍋調查」顯示，近7成(68%)受訪上班族表示曾替主管或同事揹黑鍋，同事是最常讓人揹黑鍋的肇事者占74%。慘遭揹黑鍋者大部分都不是出於自願，68%都是事後才知道自己成了冤大頭，19%是事先有共識有心理準備，11%則是因正義感而主動挺身而出。

怎樣的人是職場上容易揹黑鍋的高危險群？調查資料中，「個性太善良的」(45%)被公認是最容易揹上黑鍋的人，其次為「常狀況外，腦袋常搞不清楚狀況」(20%)、「在公司年資最淺的」(14%)和「耳根軟、太容易相信別人」(12%)。
