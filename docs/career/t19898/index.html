📘 勞動部「產業人才投資計畫」補助在職勞工

勞動部勞動力發展署辦理產業人才投資計補助在職勞工內容如下：

✍ Tiger&蘋果爸 · 2016-03-08

勞動部勞動力發展署辦理產業人才投資計補助在職勞工內容如下：

補助對象：1.年滿15歲以上

2.具有勞保、農保或漁保

補助方式：報名時先繳全額訓練費用，上課結訓後將退還給學員

(1)一般民眾政府補助80%，個人負擔20%

(2) 特定對象全額補助100%(中高年齡45歲以上、身心障礙、中低收入戶…)

以下附件為AUTOCAD相關DM，分別三場：

桃園場

上課時間：105/06/25-105/08/20，每週六09:00-16:00，共計54小時

上課地點：桃園市桃園區民族路42號(桃園火車站附近)

嘉義場：

上課時間：105/04/16-105/06/18，每週六09:00-16:00，共計51小時

上課地點：嘉義市林森西路558號(嘉義火車站附近)

高雄場：

上課時間：105/05/15-105/07/17，每週日09:00-16:00，共計54小時

上課地點：高雄市三民區建國二路166 號(高雄火車站附近)
