🧊 TXTEXP指令 繪製3D立體文字

AutoCAD沒有這個 繪製立體文字 的功能，不過可以搭配指令技巧運用，來製…

✍ Tiger&蘋果爸 · 2009-03-02

AutoCAD沒有這個 繪製立體文字 的功能，不過可以搭配指令技巧運用，來製作AutoCAD立體文字喔，以下方式供你參考，有問題請再提出來~

步驟：

1.DTEXT 建立文字

2.Express工具 的 文字分解TXTEXP指令 將文字分解為 2D線段

3.REGION 將2D線段 轉成面域

4.UNION 聯集面域

5.EXTRUDE 擠出文字(輸入高度)
