📏 繪圖小技巧6 - 文字間移動

圖片：左邊為問題，右邊為解答

✍ Tiger&蘋果爸 · 2011-10-21

圖片：左邊為問題，右邊為解答

範例圖片中有一個「魚幫水水幫魚」文字物件，請問你會透過何種方式，讓圖面中文字物件改成「水幫魚魚幫水」。

解題方式不拘，方法有很多種，你可以先回答自己的方式，之後再看到我的影片解答。

說明：完成回覆可以得到 威望值+6。

註：秘訣為按住不放在拖曳。
