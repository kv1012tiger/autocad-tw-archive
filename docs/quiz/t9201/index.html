論壇的練習題目前分為二種：

一、顧問論壇(官方)提供的[測驗題]:

測驗主題會以置頂方式再發表會員通知信，因為可以獲得積分(升等)，為了公正公平起見，如解答圖片內含尺寸標註，請先不要將答案公佈(圖片設定隱藏)，成員回覆的測驗題由官方檢核其正確性，通過測驗的論壇朋友可獲得積分或威望值。

二、論壇朋友(非官方)提供的[練習題]:

這部分我們採取自由練習，您可以隨時提出問題討論(或是提供圖片討論)，回答答案圖片不需要設定隱藏，這樣彼此可以有效討論，並且驗證練習題的正確性，參與練習與討論的論壇朋友可獲得威望值。

參與測驗或練習，請記得回答以下事項:

1.完成成品圖片(動態操作範例需提供檔案或影片)

2.所用到的指令(約略說明即可)

3.使用的AutoCAD版本

4.練習範例所需時間

5.您的意見補充

注意：

測驗練習題依照不同的範例設計(2D或3D)會有不同的回答事項，相關細節及注意事項將補充在練習範例主題中。
