✍ Tiger&蘋果爸 · 2011-09-06

教學範例目標：

步驟一 >> 可讓使用者學會在標準樣版檔中新增「圖層」、「文字型式」及「標註型式」。

步驟二 >> 透過「設計中心」方式快速插入新增，規劃標準樣版檔。

步驟三 >> 「新增頁面設置」將標準樣版檔加入不同的出圖設定。

注意：操作步驟時有任何疑問請隨時提出。

[測驗題]標準作業：A1圖框製作、樣版檔設定(一)

在完成以上第一階段，製作圖框樣版檔及設定QNEW指令後，接下來我們可以針對 STAN.dwt(樣版檔)繼續加工，而什麼式加工呢，就是把工作中會用到的相關設定(如圖層、文字型式及標註型式等等)，全部把他新增在 STAN.dwt(樣版檔)中，以後只要使用QNEW指令開啟新檔案，就會存在目前圖檔中，不用再每次自行新增。

以下我分為三種方式操作，大家可以依照工作需求隨時新增，注意：需要開啟原始的STAN.dwt(樣版檔)新增，日後使用QNEW指令開啟新檔案才會有新增的設定。

步驟一、新增「圖層」、「文字型式」及「標註型式」

開啟STAN.dwt(樣版檔)，新增所需要的「圖層及圖層顏色」，再來新增需要的「文字型式」及「標註型式」，設定好關閉檔案記得要儲存。

步驟二、「設計中心」方式快速插入新增

若是不想使用手動新增，你可以選擇目前工作中的圖檔，直接插入該工作圖檔中的既有的「圖層」或「文字型式」及「標註型式」這裡特別分享使用「設計中心」方式快速插入新增，選定後需按住滑鼠左鍵方式拖曳，拖到圖檔中放開滑鼠左鍵即可插入。

步驟三、新增頁面設置

可以滿足使用不同的列表機(繪圖機)，及包含不同的圖紙尺寸或出圖比例。而圖框建立在「配置」的好處，日後可以大量批次出圖功能，並且搭配圖紙集新增「替用頁面設置」批次出圖。
