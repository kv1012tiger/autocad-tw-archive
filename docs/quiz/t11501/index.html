📏 繪圖小技巧5 - 文字改成垂直

圖片：左邊為問題，右邊為解答

✍ Tiger&蘋果爸 · 2011-10-21

圖片：左邊為問題，右邊為解答

範例圖片中有一個文字物件，請問你會透過何種方式將文字打散，讓圖面中一個文字物件的改成六個文字物件。

解題方式不拘，方法有很多種，你可以先回答自己的方式，之後再看到我的影片解答。

說明：完成回覆可以得到 威望值+6。

註：如果文字已經是「多行文字」，則不需要使用Express工具的「合併成多行文字」TXT2MTXT指令。
