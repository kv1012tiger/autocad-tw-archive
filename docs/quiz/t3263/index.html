📝 AutoCAD 運動路徑動畫練習

透過在「運動路徑動畫」對話方塊中指定設定，可確定運動路徑動畫 的動畫檔格式。…

✍ Tiger&蘋果爸 · 2009-06-17

透過在「運動路徑動畫」對話方塊中指定設定，可確定運動路徑動畫 的動畫檔格式。有數種設定可控制動畫的畫面速率、持續時間、解析度、視覺型式以 及檔案格式。必須先建立路徑物件，然後將其選取為相機路徑或目標路徑。路徑物 件可以是直線、弧、橢圓弧、圓、聚合線、3D 聚合線或雲形線。

**所以這次嘗試使用雲形線(spline)來當作路徑，並建立 動畫檔案。
