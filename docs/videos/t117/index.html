Q3:關於聚合線...

請使用「聚合線編輯」PEDIT指令 可以將一條線、弧或另一聚合線接合為一個開放聚合線，線與弧之間不能有間距(空隙)。多重物件請使用 [多重(M)]選項。

動態操作如下，有問題請再提~

如果線與弧之間有間距(空隙)。多重物件請使用 [多重(M)]選項 >> 接合(J) >> 輸入 連綴距離(適當值)
