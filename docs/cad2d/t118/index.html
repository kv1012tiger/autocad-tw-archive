📘 AutoCAD可以設定出現單位底格嗎!

因業主要求開會時 CAD圖上能出現單位底格(井字狀布滿全張圖)以方便抓比例.…

✍ Tiger&蘋果爸 · 2008-05-09

因業主要求開會時 CAD圖上能出現單位底格(井字狀布滿全張圖)以方便抓比例. 請問CAD可以這樣設定嗎 ?謝謝~

如果只是在電腦上展示方格的效果是可以透過設定，但是方格無法列印出來，必須在自己重新繪製方格才行，以下方法供你參考有問題請再提喔~

1.「鎖點」及「格點」依照需求設定單位值，在開啟「鎖點」及「格點」後，將檢視設定為 3D現架構即可。
