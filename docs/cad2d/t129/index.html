✍ Tiger&蘋果爸 · 2008-05-09

"聽說畫AutoCAD用的螢幕不能用寬螢幕" ←←← 這是錯誤的資訊

換成寬螢幕後只要調成正確的解析度即可，若調成不適合的解析度是會造成圓被壓扁的狀況。

以下為適當的解析度供你參考:

■「ViewSonic 17吋」液晶螢幕(一般) → 解析度為 1280 x 1024 像素

■「ViewSonic 19吋」液晶螢幕(寬) → 解析度為 1440 x 900 像素
