📏 AutoCAD不為人知的秘技-標註編輯

標註尺寸算是繪圖流程中最重要的部份之一，而不同的領域有不同的使用需求，所以有…

✍ Tiger&蘋果爸 · 2008-11-20

標註尺寸算是繪圖流程中最重要的部份之一，而不同的領域有不同的使用需求，所以有人習慣建立關聯式標註物件(DIMASSOC=2預設)，我在公司是習慣建立非關聯式標註物件(DIMASSOC=1)。有時呢會需要透過編輯標註，如在標註測量文字後面加入M等文字，甚至有人會直接編輯標註測量文字，將他改成一般文字(如果標註的其中一個定義點移動，則標註將不會更新)，以下提出幾個技巧與大家分享，有問題請隨時提出來一起討論~

使用 性質(Ctrl+1)或 編輯(DDEDIT)

說明:當第一次使用 編輯 時，標註測量值會呈現有灰階底色，你可以在前面或後面加入字串，亦可直接取代置換成文字。輸入 角括弧 <> 為還原標註測量值。

https://www.youtube.com/watch?v=Xmzhp-A4Qdk

https://www.youtube.com/watch?v=WepOjT4DmlI

使用「按兩下動作」

說明:這是2007的新功能，僅適用於2007以上版本。系統預設針對標註物件連續按兩下為 開啟性質對話方塊，可以透過 自訂檔(CUI) 方式來更改為 編輯(DDEDIT)，這樣一來不用下達指令，即可 按兩下 快速編輯標註文字。

https://www.youtube.com/watch?v=-rRnZ5QmjgQ

使用 標註編輯(DIMEDIT)

說明:當第一次使用 標註編輯/新值(N) 時，標註測量值會呈現 0 (有灰階底色)，你可以在前面或後面加入字串，亦可直接取代置換成文字。輸入 角括弧 <> 為還原標註測量值。

優點:他可以複選進行多重變更標註新值，以及回復原始標註測量值。

https://www.youtube.com/watch?v=M2RDby8nLdM

使用 LISP程式

說明:依照使用習慣也可以開發程式來滿足工作需求，程式的好處可以不斷改良與修正，已達到提昇工作效率目的。

dimreassoc指令:還原標註測量值(複選方式)。

dim-fixed指令:輸入取代置換成文字(單選方式)。

https://www.youtube.com/watch?v=jpIiF49sbXM

標註文字高度

標註文字高度這個可以使用「標註型式管理員」DIMSTYLE指令，快速一次修改。

※以上上述方式為個人使用心得分享，使用方式及方法依照個習慣各有巧妙不同，歡迎有興趣的朋友加入討論喔，若覺得對你優幫助也請投票支持或回帖推文一下吧!
