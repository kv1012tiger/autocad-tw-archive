📘 關於外部參考圖併入，可以批次處理嗎?

由於工作上的需求，我想將很多張圖裡面的外部參考圖併入進來，想請問有沒有可以批…

✍ Tiger&蘋果爸 · 2009-02-26

由於工作上的需求，我想將很多張圖裡面的外部參考圖併入進來，想請問有沒有可以批次處理併入外部參考的程式??

早期我都是使用 腳本檔(SCR) 或是 LISP來獲得解決，現在起AutoCAD本身就有一個 電子傳送ETRANSMIT 的功能可以滿足你的需求，請參考以下說明，有問題請再提出~

步驟:開啟圖檔 >> 儲存 >> 電子傳送ETRANSMIT >> 加入檔案 >> 修改傳送設置 >> 打勾併入外部參考 >> 確定
