📘 AutoCAD不為人知的秘技-替代捲動軸

✍ Tiger&蘋果爸 · 2008-05-15

依照每個人工作的特性，會使用檢視圖面的工具有多種，如指令式輸入、工具列或是使用滑鼠中間滾輪來平移畫面，相信有的人習慣在圖面視窗中顯示捲動軸，但是在繪圖區的底端與右側顯示捲動軸，會使繪圖區變小，再此提供一個替代方法供大家參考，不使用捲動軸的方式無須下達任何指令滿足捲動軸功能，你將會發現AutoCAD也可以這樣用喔~

PS:或許你已知道這個方法，也請分享給你週遭的朋友吧~

※秘訣※

使用按住滑鼠左鍵不放 → 再往螢幕繪圖區上、下、左、右拖曳。
