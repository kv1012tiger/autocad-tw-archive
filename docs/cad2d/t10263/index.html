主題回顧：[分享]圖塊建立在0層使用

在各位了解0層的用法後，另外還可搭配在屬性文字(ATTDEF)做成屬性圖塊!

只要在插入的時候選擇正確的目前層，以後也可以透過圖層開關控制可見性!

日後若有分解圖塊或屬性圖塊的需求，可以使用Express的BURST指令，它可以保留原來的圖層及文字內容!

PS:若使用EXPLODE指令分解，則會還原成原始建立圖塊的圖層。
