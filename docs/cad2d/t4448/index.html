AutoCAD 畫一個線一定要先設定好尺寸 為什麼不能像

SolidWorks先畫個大概圖 再用尺寸標誌線去修改圖形大小?

AutoCAD作標一堆東西都忘記了 光是畫個方型我都不會畫

1.這需使用2010版本的參數式製圖新功能，才可以像SolidWorks 那樣有智慧型尺寸!

參數式製圖是用於使用約束進行設計的一種技術。約束是套用至 2D 幾何圖形的關聯與限制。

有兩種一般約束類型：

幾何約束可控制物件之間的相互關係

尺度約束可控制物件的距離、長度、角度和半徑值
