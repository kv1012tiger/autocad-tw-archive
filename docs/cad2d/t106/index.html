重新定義圖塊的基準點方式◆

使用 AutoCAD 2006 以上版本可以使用「圖塊編輯器」來快速重新定義圖塊(BLOCK)的基準點。

「工具」功能表：「圖塊編輯器」→「圖塊編寫選項板」視窗 →「參數」標籤 → 基準點參數...重新指定即可。

※動態操作步驟如下:有問題請再提※

PS:使用 AutoCAD 2006「圖塊編輯器」編輯後圖塊即為動態圖塊，在 AutoCAD 2005以下版本可以檢視但是無法編輯使用。
