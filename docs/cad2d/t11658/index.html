📘 創意大學堂 - CorelCAD 跨檔案使用效率百分百！

上次為大家介紹使用 CorelCAD 中的「替代大字型」，透過程式指定替代字…

✍ Tiger&蘋果爸 · 2011-11-14

上次為大家介紹使用 CorelCAD 中的「替代大字型」，透過程式指定替代字型，有效排除找不到文字產生問號的狀況。本篇為大家說明「圖塊」 MAKEBLOCK 指令 及「外部參考」 REFERENCES 指令 的操作技巧，說明經由二個功能的搭配運用，可有效提升工作效率。當您在同一個檔案中若要使用相同的物件，可透過「圖塊」的方式共用，若是需要跨檔案共用 DWG 圖面，則請您使用「外部參考」的方式，可以讓各位減少重複性的繪圖步驟。

一、圖塊運用：以下範例圖檔「單元平面底圖 .dwg 」，相同使用的部分為椅子物件。

接下來我們透過「圖塊」 MAKEBLOCK 指令 將椅子定義名稱為「方椅」的圖塊物件

請建立為圖塊再複製使用，好處在於將來圖面需要設計變更，關於椅子的型式需要變換，這時就可以不用一個一個修改，只要修改其中一個「方椅」圖塊，即可同步修正所有椅子物件。

請打開「零組件」工具列，使用 EDITCOMPONENT 指令 可直接在目前的工程圖中編輯「圖塊」

選擇「方椅」圖塊後，螢幕會出現「編輯零組件」視窗，請按「確定」

此時，圖面中只會剩下一個「方椅」圖塊，其他非圖塊的物件會淡化處理（方便辨識圖塊）

當修改完椅子後（變更為圓椅）

請點選「儲存並關閉」 SAVECOMPONENT 指令

畫面中會立即同步修正目前的工程圖中所有椅子物件

二、外部參考運用：需要將此「單元平面底圖 .dwg 」跨 DWG 檔案使用，通常我們會分專案資料夾，建議把「單元平面底圖 .dwg 」放置在名稱為「 XREFS 」資料夾中，日後可以方便管理目前的工程圖及外部參考檔案。

請在「配置平面 .dwg 」中，點擊「工具」功能表 →「參考管理員」

螢幕會出現外部參考「引用」視窗，請按「附加工程圖」

請選擇「 XREFS 」資料夾中的「單元平面底圖 .dwg 」，然後按「開啟舊檔」

螢幕中接著會出現「附加參考：工程圖」視窗，請按「確定」即可

接下來就可以使用 COPY 指令「複製」，將圖面完成以下排版配置

外部參考的優點跟圖塊有點類似，他還可以跨檔案將「單元平面底圖 .dwg 」應用在不同工作需求的 DWG 圖檔中，也可以在同一個檔案複製使用。假設將來圖面需要設計變更，關於開門的位置需要變換，這時就可以直接開啟「單元平面底圖 .dwg 」修改，即可同步更新目前的配置平面圖。

請選取其中一個外部參考，然後按滑鼠右鍵，選擇「開啟參考」

會直接開啟「單元平面底圖 .dwg 」，請修改需變更的部分後，請儲存檔案並關閉

開啟外部參考「引用」視窗，選擇「單元平面底圖」按滑鼠右鍵，選擇「重新載入」

此時圖面中所有的外部參考檔會同步立即更新

關於「圖塊」及「外部參考」的使用技巧，其實還有許多延伸的操作方式，來滿足不同或特殊的工作需求，現在大家可以先從這篇教學開始正確認識「圖塊」及「外部參考」，有興趣的朋友趕緊來試試吧。
