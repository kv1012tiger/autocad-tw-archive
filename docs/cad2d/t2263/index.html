📘 AUTOCAD 橢圓如何炸開?

我是autocad R14及 R2000版本

✍ Tiger&蘋果爸 · 2009-03-16

我是autocad R14及 R2000版本

畫完橢圓後想炸開但炸不開

橢圓物件是無法炸開的，一般最快的方式是使用 AutoLISP程式來轉換處理，但若沒有程式又無程式基礎，倒是可以使用一個小技巧來達到 橢圓轉弧(聚合線) 的效果喔!

方法一:

1.請將 PELLIPSE系統變數 設定為 1 ，建立聚合線表現法的橢圓。

2.重新畫一次橢圓，這樣就可以分解炸開了。

https://www.youtube.com/watch?v=64XMkPMP5w0

方法二(更正):

輸入WMFOUT指令 >> 選擇橢圓(匯出為WMF) >> 輸入WMFIN指令 >> 選擇WMF >> 插入後即可分解。
