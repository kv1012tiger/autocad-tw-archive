✍ Tiger&蘋果爸 · 2010-11-07

AutoCAD一直以來的動畫都必須以 相機 沿著路徑來製作(如:運動路徑動畫練習)，也就是說被攝體(目標物)是靜止不動的，
如果說要製作物體本本會移動的動畫，最典型的就是使用3Dmax，也可以使用AutoCAD其他系列的產品(如)，
但是對於一般使用者而言，對於AutoCAD以外的軟體，無論在使用度、熟練度或專業度上，都是一個很大的問題。

所以這裡特別與大家分享一個AutoCAD的方式，但是步驟稍嫌繁瑣，倒是可以做出簡單動作的動畫，
，過程中須將所有動作的影格(畫格)記錄下來，以相機為例;影片一秒約30張影格，所以影格越多播放動畫的流暢度越好。


以下範例設計讓物體自轉一周，以5度為一張影格所以需要彩現72張圖，如果沒有品質要求也可以不用彩現，
如果時間上許可也可以較為複雜的動畫(如:絕對無敵autocad)，但是這個要看你的需求而定，每個人的評量(考量)都不盡相同。

步驟一：製作影格(畫格)
1.在0度先彩現一張，然後使用3D旋轉(ROTATE3D)，選取物件沿著Z軸旋轉角度5度，再來彩現圖面，連續執行72次彩現。
2.因為製作步驟上很多，這裡也提出使用巨集(連續指令)的方式，各位可以從這一篇巨集概論來了解巨集語法，巨集的語法要依照你的範例來改良，為了簡化巨集語法，可將物體放在0,0,0，這樣可以方便選取。
3.一開始巨集可以邊寫邊測試，也可以將製作過程以紙筆記錄下來，完成語法如下:
^C^CROTATE3D;0,0;;Z;0,0;5;RENDER;

PS:按鈕部份可以使用CUI自訂工具列，這裡使用工具選項板。
4.連續執行完畢後，再來就是將彩現的圖片逐一儲存下來，記得選取PNG格式。


步驟二：製作GIF動畫
1.這裡使用 PhotoScape免費軟體 製作。
2.選擇72張PNG圖檔，測試變更畫隔時間(決定播放速度)
3.選擇畫格大小，再來儲存檔案即可完成。
