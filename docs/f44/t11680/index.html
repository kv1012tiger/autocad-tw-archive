📄 [新功能]Nucleus 建模插件 for AutoCAD 2012

最近發現 AutoCAD 2012 可以下載 Nucleus 建模外掛，這對於3D建模及模擬有很大的幫助，試用了一下覺得非常有趣！…

✍ Tiger&蘋果爸 · 2011-11-16

最近發現 AutoCAD 2012 可以下載 Nucleus 建模外掛，這對於3D建模及模擬有很大的幫助，試用了一下覺得非常有趣！


外掛模擬的物件需為「網面」（網格），透過 Nucleus工具 可以將模型「指定材質」加入不同物理特性（如:皮革、棉布、絲綢等），並且根據模型物件可以自由加入「約束」或「碰撞對象」考量，再來依據環境場景賦予「重力」及「風力方向」等因素，最後直接實行模擬，模擬後的物件可以依需要轉為「曲面」貼材質用。



我想這真是太神奇了，以下測試使用了三段影片，「指定材質」方面用了皮革、棉布及絲綢進行模擬，AutoCAD版本我使用簡體版來操作，因為Nucleus 建模外掛不支援繁體中文版，應該還是看的懂啦，有問題請再提出來討論吧！

Nucleus 建模插件將 Autodesk Maya 產品中的 Nucleus 模擬引擎集成到了 AutoCAD 2012 和 Revit 2012 軟件中。設計者可以在概念設計階段通過 AutoCAD 或 Revit 中直接模擬試驗進行找形分析。 Nucleus 建模插件能即時模擬多種物理現象，如風，重力，約束和碰撞。這些可以幫助建築師生成許多無法手工建模的曲面形狀。
Nucleus 建模插件有效性
該技術預覽在2012年6月1日終止。您創建的任何設計在該日期後仍有效，但是當技術預覽結束後，Nucleus 建模插件將不再可用。

註：Nucleus 建模插件 目前僅提供英文版及簡體中文版，請至官方網頁下載。
