當您下載了網路上分享的剖面線檔(PAT)，您會如何使用呢!?
在這裡分享我的操作心得，可以分為三種方式，請依照您的使用習慣(需求)來試試吧~
範例剖面線檔(PAT)下載:(回覆主題後可見)


方式一 >> HATCH指令:
1.先把剖面線檔(PAT)放置在新增的資料夾中。
2.到AutoCAD中新增支援搜尋路徑。
3.使用HATCH指令，選用自定頁籤中的填充線樣式建立填充線。
註：一個剖面線檔只能放一個剖面線語法，HATCH指令不支援一檔多剖面線。
但可把所有剖面線語法放在預設的acadiso.pat中，即可支援HATCH指令多剖面線使用。

AutoCAD 新增自訂填充線(PAT) - HATCH指令操作


方式二 >> 設計中心(Ctrl+2):
1.打開設計中心，找到您的剖面線檔(PAT)。
2.點選展開剖面線檔，按住填充線樣式拖曳到繪圖區域以建立填充線。
註：有支援一檔多剖面線，可使用DOS語法將所有剖面線結合成一個檔案。

AutoCAD 新增自訂填充線(PAT) - 設計中心(Ctrl+2)操作


方式三 >> 工具選項板(Ctrl+3):
1.透過設計中心快速幫您建立剖面線的工具選項板。
2.直接點選填充線樣式到繪圖區域以建立填充線。
3.或按住填充線樣式拖曳到繪圖區域以建立填充線。
註：可以透過工具選項板幫您的剖面線檔分類，有點類似預設材質庫分類的作法。

AutoCAD 新增自訂填充線(PAT) - 工具選項板(Ctrl+3)操作
