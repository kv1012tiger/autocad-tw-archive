📘 AutoCAD與WIN7相容性的問題

當微軟推出新版本時，我的建議可能先不要急的升級，因為會有很多不支援低階版本的…

✍ Tiger&蘋果爸 · 2010-05-12

當微軟推出新版本時，我的建議可能先不要急的升級，因為會有很多不支援低階版本的情況產生，

如果有必要升級的話，請考量相關配套措施較好，但是可能還會隱藏錯誤的資訊，所以得好好想想再來決定是否升級。

以下二個方法供大家參考，請執行以下方法後再進行安裝。有問題請再提~

----------------------------------------------------------------

方法一：相容模式

步驟1.選取「Setup.exe」應用程式 →「滑鼠右鍵」→「內容」→「相容性」。

步驟2.「相容模式」→「內容」→ □以相容性模式執行這個程式...打勾 → 選擇 Windows XP以下版本。

----------------------------------------------------------------

方法二：程式相容性精靈

步驟1.開啟「程式相容性精靈」，請依序按一下「開始」→「控制台」→「程式」→「在此版本的 Windows 上使用較舊版的程式」。

步驟2.依照精靈的指示 → 進行下一步直到完成。

----------------------------------------------------------------
