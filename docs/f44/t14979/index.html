📘 AutoCAD 三鍵式滑鼠功能分享

話說每天都用滑鼠在畫圖，各位知道「滑鼠」有什麼隱藏功能嗎！？

✍ Tiger&蘋果爸 · 2013-01-31

話說每天都用滑鼠在畫圖，各位知道「滑鼠」有什麼隱藏功能嗎！？

除了點選工具及選擇物件外，其實還暗藏很多小技巧喔～

以下整理了相關操作，總共有六大類（六支影片），有什麼操作疑問，歡迎隨時上來提問～

各位會員朋友有發現新的方式別忘上來分享喔～

▲滑鼠中間鍵(滾輪)：

按住滾輪→ 平移動作（同PAN指令）
滾輪前滾→ 視窗畫面拉近放大 同ZOOM指令）
滾輪後滾→ 視窗畫面拉遠縮小（同ZOOM指令）
快按兩下滾輪→ 實際範圍（同ZOOM指令）

「ZOOMFACTOR系統變數」：控制滑鼠滾輪向前或向後滾動時的倍率變更。

「ZOOMWHEEL系統變數」：切換視窗畫面縮放作業的方向。

「VTENABLE系統變數介紹」：控制使用平滑視圖轉移特效。

「VTDURATION統變數介紹」：設定平滑視圖轉移特效的持續時間(以毫秒表示)。

「VTOPTION指令」：「視圖轉移特效」對話方塊。

▲滑鼠中間鍵(滾輪)＋組合鍵：

【按住滾輪】＋【Shift鍵】→ 平移動作(正交模式)

Ctrl鍵＋按住滾輪→ 平移動作(搖桿模式)

【Shift鍵】＋【按住滾輪】→ 環轉（同3DORBIT指令）

【Ctrl鍵】＋【Shift鍵】＋【按住滾輪】→ 自由環轉（同3DFORBIT指令）

▲滑鼠左鍵：

單選→ 選取動作Esc鍵取消選取
快按兩下左鍵→ 依照物件性質執行編輯指令
按住左鍵拖曳→ 單向平移動作

【窗選】按一下再按一下 → 窗選選取(使用兩點來指定選取視窗)

【框選】按一下再按一下 → 框選選取(使用兩點來指定選取視窗)

【窗選】按住並拖曳後放開 → 窗選選取(利用點選和拖曳的方式來指定選取視窗)

【框選】按住並拖曳後放開 → 框選選取(利用點選和拖曳的方式來指定選取視窗)

「PICKBOX系統變數」：設定物件選取方框大小(以像素為單位)。

「PICKDRAG系統變數」：控制繪製選擇視窗的方式。

0 使用兩點來指定選取視窗。按一下可啟動選取視窗，再按一下可完成選取。

1 利用點選和拖曳的方式來指定選取視窗。放開滑鼠按鈕可完成選取。

2 使用上述任一種方式來指定選取視窗。

▲滑鼠左鍵＋組合鍵：

【按一下】＋【按住滾輪】→ 窗選選取及平移動作(使用兩點來指定選取視窗)

單選＋按住左鍵拖曳→ 移動亮顯物件

【單選】＋【按住右鍵拖曳】→ 亮顯物件:移動物件、複製物件、貼上為圖塊

Shift鍵＋左鍵→ 移除選取動作

▲滑鼠右鍵：

快按一下右鍵→ 代表Enter動作
按住右鍵後放開→ 預設模式的快顯功能表

「SHORTCUTMENU系統變數」：控制預設、編輯和指令模式快顯功能表在繪製區中是否可用。

▲滑鼠右鍵＋組合鍵：

【Shift鍵】＋【滑鼠右鍵】→ 物件鎖點的快顯功能表

Ctrl鍵＋滑鼠右鍵→ 物件鎖點的快顯功能表

【不同的螢幕區域】＋【滑鼠右鍵】→ 依照區域特性執行快顯功能表
