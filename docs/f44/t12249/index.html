📘 AutoCAD免費網路版 - AutoCAD 易

記得之前有跟各位朋友介紹過 AutoCAD WS Plugin 安裝及使用。

✍ Tiger&蘋果爸 · 2012-02-01

記得之前有跟各位朋友介紹過 AutoCAD WS Plugin 安裝及使用。

現在Autodesk官網推出一個新的社群 >> CAD人 -- Autodesk的免费官方在线解决方案{AutoCAD 云}

其中有一個新的網路版 AutoCAD 易（第一次執行需線上安裝）

我覺得比AutoCAD WS還要好用，藉由下面的活動我在這也簡單試用，一樣可透過網路上傳分享DWG文件，同樣能在線上開圖及改圖，當然還是局限於一些基本的2D繪圖及修改工具，雖然說介面為簡體語系，不過這次比較驚艷的是竟然可以支援「快捷指令式」輸入，而且還可以「上傳3D圖檔」，透過「ViewCube」檢視模型真的很方便喔～

另外大家有時間還可以參加活動，歐特克CAD人網站有獎分享 贏IPAD大獎

“易享” 活動說明：

時間：2012年02月01日—2012年02月29日

對象：所有www.cadren.com 網站通過郵箱驗證的註冊用戶

規則：

1、以用戶收到他人分享的文件數量進行比賽，到2012年2月29日23:59，收到文件數量最多的前三名用戶獲獎；

2、所有參與用戶必須通過網站郵箱驗證（驗證方式見：“易享” 攻略）；

3、在活動期間，用戶可邀請好友通過網站分享功能給自己分享文件；

4、分享的文件必須是dwg格式，每個文件不小於200kb；

5、每個用戶每天收到的來自同一個ID的分享數最多為5個，當天超過5個的部分視為無效；

6、本活動全程設置跟踪監控，嚴禁作弊，一經發現，將取消參與資格。

活動網站： http://www.cadren.com/Activity/EShare
