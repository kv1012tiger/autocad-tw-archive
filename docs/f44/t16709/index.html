📄 關於AutoCAD DWG檔案異常容量變大-II

關於DWG檔案異常變大原因有很多種，近期發現「DGN線型」會造成檔案變大！而這個問題遠超過之前的異常狀況，一張圖可能達到100mb…

✍ Tiger&蘋果爸 · 2013-12-04

 關於DWG檔案異常變大原因有很多種，近期發現「DGN線型」會造成檔案變大！
而這個問題遠超過之前的異常狀況，一張圖可能達到100mb以上，正常清除完畢後剩下不到1mb
現在已經有嚴重災情傳出，請大家幫忙告訴大家要正視這個問題，不然會影響傳染彼此DWG圖檔～
 像我就開DWG檔開到當機...

■私房教學2課程，第41個範例有詳細解說👇

[訂購]AutoCAD 2021 私房教學2_光碟課程/線上課程

 雖然說「Autodesk官網」有釋出修復程式(僅支援2012以上版本)，但是安裝步驟稍顯複雜（方式請參考上述 DGN 線型亂碼 討論文）。
最近終於搜尋到「Autodesk Exchange 應用程式網站」，該網站有免費分享「Dwg-Purge」外掛程式，此功能也是只有支援2012以上版本。
除了可以有效處理清除過多的「DGN 線型」，而且還可清除「註冊程式」及「比例清單」，大家趕緊來試試吧！




■使用教學：Autodesk Exchange 應用程式網站
https://www.autocad-tw.com/t14107-topic

☆置於如何判定檔案為異常放大，使用者可以將圖檔物件只留下一條線，再來使用「PURGE」或「WBLOCK」，檔案若還是很大則表示DWG檔案異常。
☆2011以下版本如何處理DGN線型問題，使用者可以使用舊版(建議2008以下版本)，將圖檔使用「WBLOCK」，DWG檔案即可正常縮小。

補充：如果安裝完畢功能區沒有顯示按鈕，請試試自訂工作區開啟



▼解決方法：
步驟一：官方網站下載「Drawing Purge」，「AjilalVijayanDwg-Purge.msi」程式檔。
http://apps.exchange.autodesk.com/ACD/zh/Detail/Index?id=appstore.exchange.autodesk.com%3adrawingpurge_windows32and64%3aen

■備用載點6.0版(2016-06-03更新*回覆可見*)： https://www.dropbox.com/s/78lsfx366eb143p/AjilalVijayanDrawingPurge.zip?dl=0
■備用載點7.0版(2017-07-05更新*回覆可見*)： https://www.dropbox.com/s/m4j5ou1kzzhfybj/AjilalVijayanDrawingPurge-7.0.zip?dl=0
■備用載點8.3.0版(2020-06-02更新*回覆可見*)： https://app.box.com/s/nf1czy2r2cxkp9rmnp2dsl72cb1bngry

步驟二：安裝執行（建議關閉AutoCAD）



步驟三：新版安裝完畢，在「功能區」切換到「增益集」面板，即可使用該應用程式。

PS:舊版安裝完畢，在「功能區」切換到「外掛程式」面板，即可使用該應用程式。

※說明：程式提供二個「DWG-PURGE指令」單檔處理及「DWG-PURGE-BATCH指令」多圖檔處理。

步驟四：10個異常DWG檔，大小共170mb


步驟五：多圖檔請使用「DWG-PURGE-BATCH指令」


步驟六：選擇圖檔 → 轉為2004格式 → 共10檔案 →「Start」


步驟七：清除了過多的「線型(DGN)」及「註冊程式」


步驟八：10個DWG檔，大小縮小為5mb
