📘 AutoCAD + Design Review

這次延續上一次的主題，一般事務所在比圖時可以使用Impression來達到手…

✍ Tiger&蘋果爸 · 2009-08-26

這次延續上一次的主題，一般事務所在比圖時可以使用Impression來達到手繪效果，而其他行業及領域可能會用不到，在此也舉出使用AutoCAD來製作 3D效果圖，一般協力複委託如結構、機電及消防等，在配合建築師比圖(競圖)時，一般多以2D平面圖，而現在為了幫助建築師或競圖的評審，這時就可以使用3D效果圖，讓非專業領域的人快速了解 結構、機電及消防的系統配置，不僅展現出專業也有助於拿到案子。

再來，公司內部須考量到時間及成本，先了解公司需求後，建議可以先從原有所熟悉的軟體AutoCAD開始踏出3D的第一步，雖然市場上3D軟體眾多，而這幾年來AutoCAD在3D的技術已有明顯提昇，一般工程類別的行業使用AutoCAD 3D建模已經措措有餘，若未來有3D管線設計需求，可再來評估是否升級軟體，如使用 AutoCAD MEP 或是 Autodesk Revit MEP 來建模也行，不過需要再花另一筆購買軟體和教學的費用，如果只是純粹提供給業主的效果圖，其實使用AutoCAD來建立3D效果圖已經綽綽有餘，而且可以使用現有的AutooCAD 2D圖面來建模，這樣至少可以比較快上手!!

範例中使用AutoCAD 2010版本來建模，此範例步驟適用於AutoCAD 2007以上版本，在3D動態展示上除了製作動畫，這次我是透過輸出成 3DDWF 再搭配使用 Autodesk Design Review 來展示，有興趣的朋友可以到原廠網頁下載!!
