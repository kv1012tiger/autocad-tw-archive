📄 [密技]AutoCAD 新增自訂線型(LIN)

業界中的工程圖說，除了可以有自訂的字型、剖面線檔，還可以自訂線型，公司可以依照需求自由新增線型檔，這裡分成三種方式跟大家說明與討論…

✍ Tiger&蘋果爸 · 2011-08-05

業界中的工程圖說，除了可以有自訂的字型、剖面線檔，還可以自訂線型，公司可以依照需求自由新增線型檔，這裡分成三種方式跟大家說明與討論!
註：DWG檔案在提供給其他使用者時，若有自訂的檔案(如字型、剖面線檔或線型檔)，均需要一併提供給對方，才可以完整正確顯示圖面資訊。



方式一 >> 自訂線型檔：
使用者本身必須有編寫線型語法的能力，LIN 檔必須以 ASCII 格式儲存，並使用 .lin 副檔名，製作過程中如同寫程式一樣，需反覆練習與測試除錯~

說明：每個樣式描述子功能變數均會指定組成線型各區段的長度，以逗號分隔 (不允許有空格):
十進位正數表示該長度的下筆 (虛線) 區段。
十進位負數表示該長度的提筆 (空格) 區段。
虛線長度為 0 時，則繪製一個圓點。


上圖表示以一個 10 個圖面單位長度的線、一個 1 個圖面單位長度的空格、另一個 2 個圖面單位長度的線、一個 1 個圖面單位長度的空格、另一個 2 個圖面單位長度的線、最後一個 1 個圖面單位長度的空格開始的一種重複樣式，此樣式延續至線的長度。

☆ 線型語法如下：  
代碼:*HW,hw______ __ __ ______ __ __ _______
A,10,-1,2,-1,2,-1
1.將以上線型語法用記事本,存檔格式為 DEMO.LIN (線型檔)
2.將 DEMO.LIN 檔案存放在以下入徑:
C:\Documents and Settings\"使用者登入帳號"\Application Data\Autodesk\AutoCAD 版本\版本代號\cht\Support
3.使用線型管理員 LINETYPE 指令 載入 DEMO.LIN 線型檔,選擇 HW 即可載入。

方式二 >> 自訂線型檔(含文字)：
這個方式比較簡單，可以複製預設公制線型檔(acadiso.lin)的語法，只需要改語法的文字部分即可，至於文字字串的多寡，須適當調整線型間距空格，線型間距空格這部份可參考 方式一。

☆ 含文字線型語法如下：
代碼:*ABC_LINE,ABC line ----ABC----ABC----ABC----ABC----ABC----ABC--
A,12.7,-5.08,["ABC",STANDARD,S=2.54,U=0.0,X=-2.54,Y=-1.27],-6.35👇含文字線型語法下載：
https://app.box.com/s/yeyj6kgujcvhkqkrtyujreyktntre3cl

方式三 >> 自訂造型檔：

若要做到上述客戶自訂線型，可能要使用 Express工具 的 MKSHAPE 指令 產生原始造型檔(*.shp)及編譯造型檔(*.shx)才行，以下是將製作好的造型掛入的步驟。

◆使用者自訂造型檔  
1.使用者需要先使用 Express工具 的 MKSHAPE指令 來製作業界自訂的特殊造型，跟製作圖塊類似請先以線、聚合線、弧、圓、橢圓等物件劃出所需的造型，在建立原始造型檔(shp)，檔名可以自訂為ATLtype.shp，並產生編譯造型檔(shx)，檔名可以自訂為ATLtype.shx。


註：建立操作步驟及說明請參考以下 造型檔概述 文章。
https://www.autocad-tw.com/t17096-topic
PS:另外下一個步驟有提供編譯造型檔範例下載。

2.請將自訂產生的 編譯造型檔(ATLtype.shx) 放置在 AutoCAD 的支援路徑下，以下支援路徑以 AutoCAD 2006版本 為例:
■AutoCAD 2006版本支援路徑：
C:\Program Files\AutoCAD 2006\Support


■AutoCAD 2017版本支援路徑：


※自訂編譯造型檔(ATLtype.shx)及範例圖檔(ATLtype.dwg)下載：
載點： https://app.box.com/s/yttjof2q4qry09g67i4lfeo2zvsgejnz
備用1： https://drive.google.com/file/d/0B41hPtWnOM8QRkF1WGxsUU5YQnM/view?usp=sharing&resourcekey=0-naI6UM-P_P2TtcbLECxvsw

3.以上產生好自訂編譯造型檔之後，請再將 自訂線型語法 寫入到 AutoCAD2006 的預設公制線型檔(acadiso.lin)，使用記事本開啟後在把語法貼到最下一行，存檔後關閉 公制線型檔(acadiso.lin) 即可。
■AutoCAD2006 公制線型檔(acadiso.lin)位置：
C:\Documents and Settings\"使用者登入帳號"\Application Data\Autodesk\AutoCAD 2006\R16.2\cht\Support


☆ 自訂線型語法：
代碼:*LTYPE01,LTYPE01 __■___■___■___■__
A,.0001,-.2,[LTYPE01,ATLtype.shx,x=-.2,s=.2],-.2
*LTYPE02,LTYPE02 __□___□___□___□__
A,.0001,-.2,[LTYPE02,ATLtype.shx,x=-.2,s=.2],-.2
*LTYPE03,LTYPE03 __▲___▲___▲___▲__
A,.0001,-.2,[LTYPE03,ATLtype.shx,x=-.2,s=.2],-.2
*LTYPE04,LTYPE04 __△___△___△___△__
A,.0001,-.2,[LTYPE04,ATLtype.shx,x=-.2,s=.2],-.2


4.啟動AutOCAD2006程式，「格式」功能表：→「線型」對話方塊 →「載入」→「檔案(acadiso.lin)」→「選擇自訂線型」→「確定」。


5.以後這張圖面即可使用這4組自訂造型線型，並可調整適當的整體線型比例決定線型密度，若您掛入樣版檔中以後就不用再自行載入線型囉。


註:關於自訂線型DWG圖檔必須要有 編譯造型檔(*.shx) 才能正確無誤的顯示自訂造型線型。
