論壇會員手冊

1.非會員(訪客)有發表主題、回覆主題的權益，但只能在 交流、公告、一般、服務 四個版面發表主題。

2.註冊會員享有發表主題、回覆主題及閱讀所有版面主題之權益，特殊會員(VIP成員)可以到[VIP討論區]發表或回覆主題或是參予討論。

3.提供所有會員實務問題及操作問題解決方案，完整的觀念導入及諮詢服務。

4.提供所有會員完整功能教學及相關技術文件下載。

5.基礎入門開課教學:提供AutoCAD基礎課程教學，幫助您基礎學習路上打穩基礎。

6.進階技巧開課教學:提供AutoCAD實務進階課程教學，幫助您解決職場上的疑難雜症。

7.不定期舉辦 論壇聚會，提供所有會員功能教學及技術交流研討。

8.本論壇所有文章版權皆為發表人所有，會員須先告知引用文章或轉載文章用途，經許可使得轉載(須註明出處及作者)。

9.特殊會員(VIP成員)帳號到期前7日會發送一封簡訊告知，到期日當天會再發一封MAIL告知，一週內仍未做出回應視同放棄續約，該特殊會員帳號權益將轉為一般會員。

10.短信功能通常用於公共用途，如諮詢服務、觀念導入及論壇導引等等，為達到資訊交流透明公開請勿濫用。

*意見及感想請到 會員留言 發表您的看法及建言!!
