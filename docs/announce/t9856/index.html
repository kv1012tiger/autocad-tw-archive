目前論壇會員人數已經突破1萬3千人，感謝各界的朋友的支持與加入~

✍ Tiger&蘋果爸 · 2011-05-12

大家好:

目前論壇會員人數已經突破1萬3千人，感謝各界的朋友的支持與加入~

由於會員人數及發表的文章數也日益增加，其中有新手上路會員尚未熟悉版規而導致灌水回覆!

為了減輕管理人員的工作負擔，我們得將論壇的部份版區權限調整，也就是等級一般會員才可以發表文章及回覆文章~

這樣可維持會員瀏覽品質及保有文章價值，一開始可能會造成大家的使用困擾，但還請大家務必諒解及支持!

關於任何升等手續問題，我們歡迎您隨時提出討論或是提供建議~
