📘 號外！快速升等「初級會員」辦法-藍鵲家族...已結束

親愛的會員朋友大家好:

✍ Tiger&蘋果爸 · 2011-12-14

親愛的會員朋友大家好:

為了慶祝顧問論壇吉祥物「台灣藍鵲」誕生，也感謝各界朋友熱情響應加入支持，即日起至2012/12/31，提供一個 贈送積分+1 的方式。另外，我們還想要輔導新加入的朋友升等，若是您的會員等級為 一般會員 的朋友，經審核無誤後還可升等為 初級會員。

注意事項：

1.若您已經加入藍鵲家族，只需要再到 AutoCAD粉絲團 按讚後留言，留言時請簡短發表您的建議或是感想即可，記得補上您的論壇會員帳號。

2.您需要擁有Facebook帳號才能按讚留言，若是無Facebook帳號，可以透過另一個方式獲得積分 >> 串連貼紙-CAD網站分享（點我）。

3.「論壇回覆文章」及「粉絲團留言」均不得少於10個字，請您多一點正面鼓勵與互動。

獲得積分方式（加入藍鵲家族 + 粉絲團留言）:

一、認同AutoCAD顧問論壇，請您一同加入藍鵲家族！

加入藍鵲家族（點我）

二、在AutoCAD粉絲團按讚+留言（記得補上論壇會員帳號）

AutoCAD粉絲團（點我）

註：完成以上二個步驟後，我們會依據在AutoCAD粉絲團中的留言及帳號幫您加積分，若是疏忽遺漏掉您的積分，請發短信 （Tiger&蘋果爸）通知審核。

補充：等級為為 新手上路 的朋友，請您撥空完成「回覆五篇指定文章」，完成後請發信通知管理員或是到「會員留言版」發表文章申請升等審核，論壇管理員會盡速審核您的回文完成升等。

升等辦法:回覆規定五篇文章，立即升等一般會員:

http://autocad.bestoforum.net/t1685-topic
