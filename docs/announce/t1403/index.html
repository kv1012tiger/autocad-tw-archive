📘 顧問論壇等級權限

文章數限制須達200篇、積分20分、威望值200。

✍ Tiger&蘋果爸 · 2008-12-27

文章數限制須達200篇、積分20分、威望值200。

文章數限制須達300篇、積分30分、威望值300。

升等資格說明：

初級成員：無文章數限制。

中級成員：文章數限制須達50篇。

高級成員：文章數限制須達100篇。

特殊成員：可以使用贊助方案來升等。

論壇志工：熱心、有共識、熱心解決論壇使用問題。

2011/03/02新增等級

榮譽顧問：文章數限制須達200篇、積分須達20分。

專業顧問：文章數限制須達300篇、積分須達30分。
