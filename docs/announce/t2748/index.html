📘 串連貼紙-CAD網站分享

首先感謝您加入AutoCAD顧問論壇，現在起您可以使用「串連貼紙-CAD網站…

✍ Tiger&蘋果爸 · 2009-04-30

各位好:

首先感謝您加入AutoCAD顧問論壇，現在起您可以使用「串連貼紙-CAD網站分享」！

把我們這個平台告訴你們的好朋友，方法很簡單請按照以下影片方式完成串連即可。

PS:目前奇摩部落格、天空網誌、無名網誌的串連語法都OK。

請完成以下二個步驟：

1.當您在您的部落格或個人網站串聯成功，請記得發文回帖通知我。

(請留下您的部落格或個人網站網址)

2.認同AutoCAD顧問論壇，請您一同加入藍鵲家族！

https://www.autocad-tw.com/t11850-topic

註：經確認後論壇將給予積分+1，謝謝您撥空完成串連，也可落實互助精神喔~

會員等級為「一般會員」擁有積分1的朋友，立即升等為「初級會員」，即可獲得更多的論壇資源幫助!
