二、各版區整合及瀏覽權限已設置完畢，團隊成員可以查看以下版區規劃示意圖及等級權限說明圖。

顧問論壇版區規劃

https://www.autocad-tw.com/forum-f6/topic-t1402.htm

顧問論壇等級權限

說明：為求落實互助精神，論壇開始實施積分制度，在這裡只要您願意加入分享的行列，我們會非常樂意幫您累積積分，只要您發揮回覆文章的美德，在您的每次回覆的鼓勵文字，這將是支持我們堅持下去的動力，因為要怎麼收穫請先那麼栽，願意付出的成員可以得到更大的幫助。

對於願意回文與分享的成員，各版區的流覽權限是很低的門檻，但是對於少部分潛水或只是下載資源的成員，可以有效阻止濫用這論壇寶貴的資源，另外，在這裡我們歡迎有志一同的朋友，決心要一起來建構這互助共享平台的朋友，我們竭誠邀請您加入論壇志工的行列，發揚論壇理念 魚幫水、水幫魚。

三、新加入的成員及未發文的成員，請先完成報到，當您報到完畢請發短信通知管理員，我們將會升等您的會員等級為 一般會員。

說明：對於改版之前的舊成員，仍然需要完成報到動作，當您報到完畢請發短信通知管理員，我們將會開放您「技術討論區」發表文章權限。有任何使用問題的成員請至「會員留言」發表主題。

[新手請進]升等辦法:發表一篇報到文章，立即升等一般會員!!

https://www.autocad-tw.com/forum-f14/topic-t1685.htm

四、關於 討論區 中的 功能分享、資源分享，這些版區是分享專區，只要您願意落實互助精神，我們會依照您的積分紀錄幫您升等等級，慢慢的你會發現幫助別人是這麼快樂的，希望所有成員可以一起加入互助的行列，當您付出的越多相對得到的資源也就越多。

說明：瀏覽權限部份有任何疑問歡迎到 訪客留言，若您的權限等級沒有依照積分及回文章數來升等，請您即刻通知管理員，我們將在最短時間幫您升等。
