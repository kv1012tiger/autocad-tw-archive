📢 積分說明

關於論壇 積分制度 很多人有著不同的意見，在此提出說明，有建議的成員們請您一…

✍ Tiger&蘋果爸 · 2009-07-21

大家好:

關於論壇 積分制度 很多人有著不同的意見，在此提出說明，有建議的成員們請您一起提出來討論!!

對於一般會員給予積分我們會比較寬鬆，互動良好、參與練習題或是串連貼紙都可快速得到積分1，即可升等初級會員。

而發文回帖(文章數)並不是獲得積分的主要方法，最重要的是互助及互動，幫助人並不一定要專業的知識，哪怕只是簡單的回文提醒或是好文轉貼，這個就是動機(表示你是很有心的)，我們不會吝嗇加分的，另外對於只是為了獲取積分的回帖，我們會斟酌情形給予的。總之有機會隨時你都可以幫助人，要怎麼收穫請先那麼栽!!

我想在這裡應該不要那麼在意績分，重要的是能在這裡學到職場上學不到的知識，有緣分的話還可以交到朋友，這是我們建立論壇的初衷，希望大家都能像朋友一樣互相幫忙，朋友之間是真誠的沒有心機的!

慢慢的我們可以從和你的互動、文章數及積分，竟而了解您是否是真的很有心願意一起在這打拼，這也就是我們一直再找尋的志同道合的朋友，只要你能認同參予加入我們的行列，你會發現幫助人可以是那麼簡單及快樂的!

我相信在這裡應該有很多人得到幫助，我也看見很多人願意無私提供協助，但是那些接受別人幫助的成員，下次碰到跟你一樣問題的成員，你是否願意實現互助理想提供幫助呢...很多人想要來這裡學東西，但我更想要你學到東西不是拍拍屁股走人，所以對於發表主題後未回應的成員，這真的是讓人感到心灰意冷!!

論壇這裡正在做的事(理念)有別於一般的論壇，我想可能多人不習慣，我想這是我的的原則也是我們的價值所在，這樣大家才會珍惜這個園地以及珍惜您的帳號，如果您是從一開始就參與的會員，應該知道以前論壇沒有積分限制，大家都是來挖資源及灌水，這樣的狀況很難永續經營，我也曾經想過幹嘛這麼累，經過內部討論才有所謂的積分制度，論壇也才能凝聚這麼多的朋友，這證明我們走的路及方向是對的，所以希望大家能多多支持!

補充：另外論壇中有很多機會可以馬上獲得積分1，請剛加入的朋友別急，慢慢的花點時間爬文，你會發現得到積分不是很困難!
