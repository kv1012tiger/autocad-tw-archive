📢 imageshack 圖片空間使用說明

目前論壇系統預設上傳的圖片空間為 imageshack(青蛙)

✍ Tiger&蘋果爸 · 2011-03-07

目前論壇系統預設上傳的圖片空間為 imageshack(青蛙)

之前該空間更改為需要註冊登入的會員才能看得到圖片~

經過我們向 imageshack(青蛙) 申請後，現在可以不需要註冊登入就可看的到圖片!

所以各位朋友可以在繼續使用此空間上傳圖片~

另外也可使用自己的圖片空間上傳(建議使用Windows Live空間)

若有任何問題也請大家立即回報給我們!!
