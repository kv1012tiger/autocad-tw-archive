贊助A會員 新增升級 🔧 指令名稱

4️⃣M2MS（Model to Mview Selection）:

模型空間(矩形物件)，轉換配置空間單一或多重配置(視埠view)。

🎯 功能簡述

👉 在 Model 空間選取物件

👉 自動在 多個 Layout（圖紙）建立對應視埠（Viewport）

👉 並且 縮放到該物件範圍 + 鎖定視埠

⚙️ 操作流程（超精簡版）

1 讀取預設範圍（PSET儲存的框選座標）

2 在 Model 空間選取一個物件

3 取得該物件外框範圍（Bounding Box）

4 選擇要套用的 Layout（DCL介面）

5 自動執行：

建立視埠

Zoom 到物件

鎖定視埠

排到最底層（避免遮擋）

其實你只差一個指令！選物件 → 一鍵自動幫你在所有 Layout 建好視埠＋對準＋鎖定🔥
