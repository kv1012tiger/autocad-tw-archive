----------------------------------------------------------------------

面積欄位命令

----------------------------------------------------------------------

指令: AF

說明: 計算選擇物件的總面積，使用當前單位，顯示6位小數，包含減法提示（可選擇要減去的面積）。

指令: AFM

說明: 計算選擇物件的總面積，使用當前單位並將平方毫米(mm²)轉換為平方公尺(m²)，顯示6位小數。

指令: AMM2

說明: 計算選擇物件的總面積，將平方毫米(mm²)轉換為平方公尺(m²)，顯示2位小數。

指令: ACMM2

說明: 計算選擇物件的總面積，將平方公分(cm²)轉換為平方公尺(m²)，顯示2位小數。

指令: AAMM2

說明: (前綴面積:) 計算選擇物件的總面積，將平方毫米(mm²)轉換為平方公尺(m²)，顯示2位小數。

----------------------------------------------------------------------

長度欄位命令

----------------------------------------------------------------------

指令: LF

說明: 計算選擇物件的總長度，使用當前單位，顯示6位小數，包含減法提示（可選擇要減去的長度）。

指令: LFM

說明: 計算選擇物件的總長度，使用當前單位並將毫米(mm)轉換為公尺(m)，顯示6位小數。

轉換因子: 0.001 (1mm = 0.001m)
