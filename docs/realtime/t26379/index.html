工作中常常會需要每張圖檔作同樣步驟😅

例如：每張梁配筋都要加圖框，並且完成配置視埠及比例。

這時可以將操作步驟寫成SCR腳本檔

然後讓AutoCAD自動完成所有圖檔😎

不管你會不會用，但你一定要知道學起來之後
