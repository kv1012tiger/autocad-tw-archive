😁這回是【贊助A外掛工具】實務整合應用

依照業界使用習慣設計了二個範本進行操作

當插入所有圖檔後，分為模型空間及配置空間套圖框，最後批次出圖。

😎外掛程式總共使用下列工具:

1️⃣ DWGIN 指令:

可選擇插入(I) 或 外部參考(X) 方式組合。

說明: https://www.autocad-tw.com/t29873-topic

2️⃣ CDS 指令:

查詢圖面範圍，按照圖框大小，提示最佳出圖比例。

說明: https://autocad-tw.1shop.tw/pgodd8

3️⃣ P5 指令:

選擇圖面物件，逐一從剪貼簿貼上(物件插入點)。

說明: https://www.autocad-tw.com/t28538-topic

4️⃣ DP 指令 DPLA 指令:

支援【配置空間】一檔多配置出圖，支援【模型空間】一檔多圖框圖塊出圖電子PDF檔。

說明: https://www.autocad-tw.com/t27512-topic

5️⃣ STP 指令:

自動匯入【出圖樣版檔】頁面設置，模型空間及配置空間各有三組可供匯入頁面設置。

說明: https://www.autocad-tw.com/t27512-topic

6️⃣ PSET 指令:

指定配置空間之視埠範圍(繪圖區範圍)。

說明: https://www.autocad-tw.com/t28109-topic

7️⃣ M2MM 指令:

【繪圖區範圍】圖塊，模型空間轉換配置空間的視埠建立多重配置。

說明: https://www.autocad-tw.com/t28109-topic
