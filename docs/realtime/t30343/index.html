這題看起來像三顆圓排一排那麼簡單？

結果一畫下去整個崩潰：角度不對、圓心跑掉、弧線永遠貼不齊。

完全是技能檢定的精神攻擊。

但其實它有固定套路：

先抓扇形中心 → 用 R100 找圓心基準 → 三圓等角切分定位 → 最後補弧線。

懂了之後超順、完全不痛苦。

影片帶你一步秒懂，不再被這種題目打爆。
