😎外掛程式總共使用下列工具:

1️⃣ DWGIN 指令:

可選擇插入(I) 或 外部參考(X) 方式組合。

說明: https://www.autocad-tw.com/t29873-topic

2️⃣ CDS 指令:

查詢圖面範圍，按照圖框大小，提示最佳出圖比例。

說明: https://autocad-tw.1shop.tw/pgodd8

3️⃣ P5 指令:

選擇圖面物件，逐一從剪貼簿貼上(物件插入點)。

說明: https://www.autocad-tw.com/t28538-topic

4️⃣ DP 指令 DPLA 指令:

支援【配置空間】一檔多配置出圖，支援【模型空間】一檔多圖框圖塊出圖電子PDF檔。

說明: https://www.autocad-tw.com/t27512-topic

5️⃣ STP 指令:

自動匯入【出圖樣版檔】頁面設置，模型空間及配置空間各有三組可供匯入頁面設置。

說明: https://www.autocad-tw.com/t27512-topic

6️⃣ PSET 指令:

指定配置空間之視埠範圍(繪圖區範圍)。

說明: https://www.autocad-tw.com/t28109-topic

7️⃣ M2MM 指令:

【繪圖區範圍】圖塊，模型空間轉換配置空間的視埠建立多重配置。

說明: https://www.autocad-tw.com/t28109-topic

✨程式有更新✨

✨DWG檔組合使用說明✨

1.在指令行中輸入 DWGIN 並按 Enter 鍵，開始運行此程式。

2.選擇插入方式：

程式會提示選擇插入方式，您可以選擇插入(I) 或 外部參考(X) 方式。如果不選擇，會使用上次運行程式時的選擇或預設的插入(I) 方式。

3.選擇 DWG 文件：

程式會彈出一個文件對話框，讓您選擇一個 DWG 文件。選擇文件後，程式會自動檢索該文件所在資料夾中的所有 DWG 文件。

4.自動插入並排列 DWG 文件：

程式會自動將資料夾中的所有 DWG 文件插入到當前圖紙中，並根據上一個插入文件的最大範圍進行排列，確保文件之間有一定的間隔。

5.完成插入並顯示結果：

當所有文件插入完成後，程式會自動將視圖設置為全圖顯示，並在命令行中顯示成功訊息，包括插入的 DWG 文件數量和資料夾路徑。
