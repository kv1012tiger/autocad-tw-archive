💻 如何讓 標示線長度程式 升級優化

課程範例 D12.程式-標示線長度 優化程式

✍ Tiger&蘋果爸 · 2025-04-01

✨指令說明✨

1️⃣ DimLines11 指令

選取多個線標示線長度。

程式優化說明:

1.同一個矩形，有二個邊界長度一樣 邊界線的點位一樣 不要重複標註

2.邊界線的點位不一樣 要重複標註

3.正矩形 有四個邊界一樣 需要標註二個方向(水平及垂直)

4.檢查邊界長度 加入公差0.1
