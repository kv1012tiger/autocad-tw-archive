這支影片教你用「組合圖檔＋批次出圖」的超神技巧，

讓出圖速度從 3小時 ➜ 3分鐘🔥

一次搞定所有平面圖、施工圖、出圖框，全自動生成✅

AutoCAD 出圖不再卡，不再慢！絕對是提升效率的必學神招🚀

😎外掛程式總共使用下列工具:

1️⃣ DWGIN 指令:

可選擇插入(I) 或 外部參考(X) 方式組合。

說明: https://www.autocad-tw.com/t29873-topic

2️⃣ P4L 指令:

選擇圖面圖塊物件，逐一從剪貼簿貼上(插入點+套用圖層)。

說明: https://www.autocad-tw.com/t28538-topic

3️⃣ STP 指令:

自動匯入【出圖樣版檔】頁面設置，模型空間及配置空間各有三組可供匯入頁面設置。

說明: https://www.autocad-tw.com/t27512-topic

4️⃣ DPLA 指令:

支援【配置空間】一檔多配置出圖，支援【模型空間】一檔多圖框圖塊出圖電子PDF檔。

說明: https://www.autocad-tw.com/t27512-topic
