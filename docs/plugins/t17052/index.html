💻 外掛程式沒有地方放置

DANDYYEUNG 寫到:我每次轉換做3D 格式的時候, 外掛程式列就好像被人掉出家門, 當我回到普通格式的時候我要一個一個放好他，你有沒有解決方法。

關於顧問外掛程式的工具，可以透過 新增工作區（儲存）。

1.開啟「工作區」設置，設定為「自動儲存工作區設定」。

2.再來把工具列擺放好位置。

3.另存一組「工作區」名稱，這樣以後切換「工作區」設置就不會跑掉。
