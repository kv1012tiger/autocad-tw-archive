Q1：安裝ACADAdviser外掛程式後，是否可以在同一部電腦中其他AutoCAD版本？

A1：目前只能安裝再同一部電腦中一套AutoCAD，無法安裝再其他AutoCAD版本。

Q2：請問現在裝在目前電腦裡面使用，之後若升級電腦主機或電腦重灌時，是否ACADAdviser外掛程式還可以安裝一次，如果不行是否說要再付費才行？

A2：這樣不需要再多支出費用，當用戶「升級電腦主機」或「電腦需重灌」時，必須先「移除主程式」，提供回傳「移除訊息畫面」，然後再次執行「安裝路徑偵測」步驟，接著完成「主程式安裝」步驟即可。

註：用戶若是因「電腦當機/壞掉」無法提供「移除訊息畫面」，恕不提供「授權轉移」服務。

Q3：我在第一間公司安裝後，現在換工作了可以把外掛程式帶走使用嗎？

A3：當使用者轉換公司(工作)時，請先移除原公司之「ACADAdviser外掛程式」，並且提供回傳「移除訊息畫面」確認完成「轉移授權」。

再至新公司執行「安裝路徑偵測步驟」，並將「記錄檔」提供回傳，我們會再將「主程式」寄給您，用戶只要再完成「主程式安裝步驟」，即可將「外掛程式」重新安裝在新公司電腦中。

Q4：我已經使用過一次授權轉移，現在又再度換供工作怎麼辦，是否要多花費用安裝？

A4：用戶申請「轉移授權」以一次為限，無提供二次「轉移授權」服務。

Q5：我們公司的電腦是有新人來，舊的電腦就轉給新人使用，舊同事再換成新電腦，這樣的話如何轉移授權？

A5：這情況可以多次「轉移授權」以一次為限，用戶只需提供移除舊電腦之「ACADAdviser外掛程式」畫面(圖片)證明，再至新電腦執行「安裝路徑偵測步驟」，並將「記錄檔」提供回傳，我們會再將「主程式」寄給您，用戶只要再完成「主程式安裝步驟」，即可將「外掛程式」重新安裝在新電腦中。

Q6：外掛工具操作有疑慮時，我該在哪裡尋求幫助？

A6：可以到AutoCAD顧問論壇「外掛程式區」發問主題，版區中有工具按鈕「圖文說明」及影片教學，可以幫您解決疑慮。

外掛程式區： https://www.autocad-tw.com/f66-forum

Q7：這ACADAdviser外掛程式是否能用在LT版本呢？

A7：因為原廠軟體設定問題，AutoCAD LT版本不能支援加載「外掛程式」及使用「3D功能」。

Q8：我的電腦中有其他AutoCAD，是否也可以使用ACADAdviser外掛程式，有沒有CAD版本限制呢？另外，可以安裝在其他電腦嗎？

A8：「ACADAdviser外掛程式」只能安裝授權在「一部電腦」中，僅可安裝同一部電腦中的一套「AutoCAD版本」。目前可支援AutoCAD 2016~2024版本（Windows作業系統），使用者可以選擇常用的AutoCAD版本進行「安裝路徑偵測步驟」。

Q9：安裝的時候是否會與其他LISP外掛程式有衝突？

A9：因為「加載安裝方式」及「支援搜尋路徑」不同，原則上不會有這種情況發生，如果有衝突請回報，我們將立即為您解決。

Q10：：原本的「支援檔搜尋路徑」不小心刪除，造成外掛程式沒辦法使用？

A10：可以再使用附件(安裝路徑偵測.zip)，執行「安裝路徑偵測步驟」自動幫您加上路徑。

註：步驟九:外掛程式會預先在「AutoCAD 版本」中，加入「支援檔搜尋路徑」。

Q11：安裝時是否需要序號，有使用期限限制嗎？

A11：安裝「ACADAdviser外掛程式」不需序號，是自動綁定用戶電腦，使用上沒有時間限制。

Q12：目前使用為ACADAdviser 1.0第一版之外掛，論壇推出新的更新版本，請問我的外掛能使用更新嗎？

A12：只要是在「贊助會員」期限內，每一套「ACADAdviser外掛程式」，都可享有免費「軟體更新」服務。

Q13：有沒有另外一種不用綁定電腦的方式？或者其他方案？

A13：因為論壇的「外掛程式」是附贈軟體，主要是提供會員問題討論解決服務，所以目前沒有提供「無綁定電腦」的方式，其他使用方案尚在研擬規劃中。

Q14：因為電腦有時候遇到重灌AutoCAD,就沒辦法再繼續用了嗎？

A14：授權的電腦如果需要重灌AutoCAD，原先提供給您的「外掛程安裝檔式」，可以再安裝重灌回AutoCAD(同一部電腦)，一樣使用無期限。

因為贊助會員之「外掛程式」採用贊助贈予使用，外掛程式得以比較平價。

若是以市面上外掛程式軟體行情，外掛程式價格就會太貴，所以我們不採用這方案。

而這二者各有優缺點，像市面上外掛程式採序號買斷，也就是用戶可自行移除重裝，真正達到永久使用之定義。

所以我們的外掛程式「授權轉移」服務，是以贊助會員期限來界定。
