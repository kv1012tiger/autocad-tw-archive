工具按鈕說明

[列示文字性質]TextList指令：列示所選文字物件性質。

[列示文字,圖塊位置]ListBlkTxt指令：圖面中亮顯顯示，所選文字物件或圖塊物件位置。

[列示面積]QArea指令：計算圖面中封閉區域，列示加總面積及轉換為坪數(才數)。

[列示面積<牆>]QAreaWall指令：輸入牆壁厚度，計算圖面中封閉區域，列示加建築總面積及轉換為坪數。

[列示長度]QLength指令：列示所選物件之長度資訊。

[查詢面積]SArea指令：查詢所選封閉區域面積及轉換為坪數。

[查詢長度]SLength指令：查詢所選物件之長度資訊。

[查詢座標]連續查詢物件座標資訊。
