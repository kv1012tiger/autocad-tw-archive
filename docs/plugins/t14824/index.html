工具按鈕說明

[DWG檔案清單偵測]AutoScript指令：在目標資料夾中偵測所有DWG檔案，並建立DWG檔案名稱清單。

[開啟自動化腳本檔...]QSCR指令：開啟SCR自動化腳本檔。

[開啟DWG檔案清單...]QDWG指令：開啟DWG檔案名稱清單。

[清除圖層過濾器]SCR1指令：開啟DWG檔案名稱清單中之圖檔，自動執行「清除圖層過濾器」批次作業。

[清除圖檔]SCR2指令：開啟DWG檔案名稱清單中之圖檔，自動執行「清除圖檔」批次作業。

[清除註解比例]SCR3指令：開啟DWG檔案名稱清單中之圖檔，自動執行「清除註解比例」批次作業。

[圖檔修復]SCR4指令：開啟DWG檔案名稱清單中之圖檔，自動執行「圖檔修復」批次作業。

[外部參考併入]SCR5指令：開啟DWG檔案名稱清單中之圖檔，自動執行「外部參考併入」批次作業。

[使用者自訂]SCR6指令：使用者自訂輸入巨集語法，自動執行「自訂巨集」批次作業。
