工具按鈕說明

[刪除頁面設置]DPagesetup指令：刪除目前圖面中所有頁面設置。

[指定頁面設置]MPagesetup指令：指定目前圖面中目前頁面設置。

[多配置轉單一配置]Layout2Dwg指令：圖面中所有多配置，匯出單一配置至新圖面(DWG)的配置空間。

[多配置轉單一模型]Layout2Model指令：圖面中所有多配置，匯出單一配置至新圖面(DWG)的模型空間。
