「輔助設計I」工具列
工具按鈕說明

[多重圓角]MultipleRad指令：複選選取2D聚合線，全部建立圓角。

[多重倒角]MultipleCha指令：複選選取2D聚合線，全部建立倒角。

[多重雲形線]RevcloudMul指令：多重連續建立雲形線。

[雲形線結合]RevcloudJoin指令：結合雲形線。

[中心正方形]RECTANGC指令：建立中心正方形。

[中心矩形]RECTANGWH指令：建立中心矩形。

[矩形交叉]RectangInt指令：建立矩形交叉線。

[交叉線]IntLine指令：建立交叉線。
