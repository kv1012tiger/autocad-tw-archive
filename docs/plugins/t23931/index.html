💻 ATStruCAD結構外掛程式 - Q&A

Q1：安裝ATStruCAD結構外掛程式後，是否可以在同一部電腦中其他Aut…

✍ Tiger&蘋果爸 · 2020-07-07

Q1：安裝ATStruCAD結構外掛程式後，是否可以在同一部電腦中其他AutoCAD版本？如何安裝結構外掛程式？

A1：目前只能安裝在同一部電腦一套AutoCAD版本中，外掛程式無法再安裝至其他AutoCAD版本。結構外掛程式安裝方式採用網路「遠端線上安裝」。

Q2：請問現在裝在目前電腦裡面使用，之後若升級電腦主機或電腦重灌時，是否ATStruCAD結構外掛程式還可以安裝一次，如果不行是否說要再付費才行？

A2：這樣不需要再多支出費用，當用戶「升級電腦主機」或「電腦需重灌」時，必須先申請「遠端移除主程式」，然後再次執行「安裝路徑偵測」步驟，接著完成「遠端主程式安裝」步驟即可。

註：若無先申請使用「遠端移除主程式」，恕不提供「授權轉移」服務。用戶若是因「電腦當機/壞掉」，特殊情況以一次為限，需提供檢修電腦證明單據，始可重新授權（三年內免費「重新授權」服務）。

Q3：我在第一間公司安裝後，現在換工作了可以把外掛程式帶走使用嗎？

A3：當使用者轉換公司(工作)時，必須先申請「遠端移除主程式」，移除原公司之「ATStruCAD結構外掛程式」，確認完成「轉移授權」。

再至新公司執行「安裝路徑偵測步驟」，並再將「記錄檔」提供回傳，我們會透過網路「遠端線上安裝」，即可將「結構外掛程式」重新安裝在新公司電腦中。

註：用戶申請使用「授權轉移」服務（三年內免費「重新授權」服務）。

Q4：我已經使用過一次授權轉移，現在又再度換供工作怎麼辦，是否要多花費用安裝？

A4：用戶需先再次申請「遠端移除主程式」，移除原公司之「ATStruCAD結構外掛程式」，完成「轉移授權」步驟，即可再次申請網路「遠端線上安裝」服務。

Q5：我們公司的電腦是有新人來，舊的電腦就轉給新人使用，舊同事再換成新電腦，這樣的話如何轉移授權？

A5：用戶需先再次申請「遠端移除主程式」，移除原公司之「ATStruCAD結構外掛程式」，完成「轉移授權」步驟，即可再次申請網路「遠端線上安裝」服務。

Q6：結構外掛工具操作有疑慮時，我該在哪裡尋求幫助？

A6：可以到AutoCAD顧問論壇「外掛程式區」發問主題，版區中有工具按鈕「圖文說明」及影片教學，可以幫您解決操作問題及疑慮。

外掛程式區： https://www.autocad-tw.com/f66-forum

Q7：這ATStruCAD結構外掛程式是否能用在LT版本呢？

A7：因為原廠軟體設定問題，AutoCAD LT版本不能支援加載「外掛程式」及使用「3D功能」。

Q8：我的電腦中有其他AutoCAD，是否也可以使用ATStruCAD結構外掛程式，有沒有CAD版本限制呢？另外，可以安裝在其他電腦嗎？

A8：「ATStruCAD結構外掛程式」只能安裝授權在「一部電腦」中，僅可安裝同一部電腦中的一套「AutoCAD版本」。目前可支援AutoCAD 2016~2024版本（Windows作業系統），使用者可以選擇常用的AutoCAD版本進行「安裝路徑偵測步驟」。

Q9：安裝的時候是否會與其他LISP外掛程式有衝突？

A9：因為「加載安裝方式」及「支援搜尋路徑」不同，原則上不會有這種情況發生，如果有衝突請回報，我們將立即為您解決。

Q10：：原本的「支援檔搜尋路徑」不小心刪除，造成外掛程式沒辦法使用？

A10：請重新匯入紀要設置即可，紀要路徑：C:\ATStruCAD\*版本*\ATStruCAD*版本*.arg。請選擇目前安裝的版本，以下以2021版本為範本。

AutoCAD中輸入OPTIONS指令，開啟「選項」>「紀要」>「匯入」>「C:\ATStruCAD\2021\ATStruCAD2021.arg」>「設為目前的」>「確定」。

Q11：安裝時是否需要序號，有使用期限限制嗎？

A11：安裝「ATStruCAD結構外掛程式」不需序號，是自動綁定用戶電腦，正式版使用上沒有時間限制，試用版有時間限制。

Q12：目前使用為ATStruCAD結構 1.0第一版之外掛，論壇推出新的更新版本，請問我的外掛能使用更新嗎？

A12：每一套「ATStruCAD結構外掛程式」，購買安裝後可享有三年內免費「軟體更新」服務。

Q13：有沒有另外一種不用綁定電腦的方式？或者其他方案？

A13：目前沒有提供「無綁定電腦」的方式，其他使用方案尚在研擬規劃中。
