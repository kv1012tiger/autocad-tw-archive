「輔助巨集」工具列
工具按鈕說明

[物件圖層設為0]LayerChange0指令：設置目前層為0層及物件圖層變更為0層。

[多邊形圓形選取]WPSelect指令：透過多邊形窗選範圍或圓形窗選範圍選取圖面物件。

[旋轉參考對齊]旋轉物件使用參考對齊方式。

[對齊物件UCS]對齊物件UCS。

[對齊世界UCS]對齊世界UCS。

[對齊標註線]AlignDIMEXA指令：複選選取標註，對齊標註線。

[對齊延伸線]AlignDIMEXB指令：複選選取標註，對齊延伸線。
