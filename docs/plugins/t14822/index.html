💻 ACADAdviser外掛程式 - 標註應用工具說明

※標註應用工具列：

✍ Tiger&蘋果爸 · 2013-01-08

※標註應用工具列：

工具按鈕說明

[變更標註內容]EditDimTxt指令：變更標註文字內容。

[還原測量值 <>]DIMA1指令：還原標註測量值<>。

[附加新值 W=<>]DIMA2指令：標註測量值<>，後方附加"W="字串。

[附加新值 L=<>]DIMA2A指令：標註測量值<>，後方附加"L="字串。

[附加新值 直徑<>]DIMA7指令：標註測量值<>，前方附加"直徑"符號。

[附加新值 <>正負]DIMA9指令：標註測量值<>，後方附加"正負"符號。

[附加新值 <>(TYP.)]DIMA10指令：標註測量值<>，後方附加"(TYP.)"字串。

[附加新值 <>(MAX.)]DIMA11指令：標註測量值<>，後方附加"(MAX.)"字串。

[附加新值 <>(MIN.)]DIMA12指令：標註測量值<>，後方附加"(MIN.)"字串。

[附加新值 <>度]DIMA8指令：標註測量值<>，後方附加"度"符號。

[附加新值 <>m]DIMA4指令：標註測量值<>，後方附加"m"字串。

[附加新值 <>mm]DIMA4A指令：標註測量值<>，後方附加"mm"字串。

[變更新值 S.A.D.]DIMA3指令：標註測量值<>，變更新值為"S.A.D."字串。

[變更新值 EQ.]DIMA6指令：標註測量值<>，變更新值為"EQ."字串。

[變更新值 Ld]DIMA5指令：標註測量值<>，變更新值為"Ld"字串。
