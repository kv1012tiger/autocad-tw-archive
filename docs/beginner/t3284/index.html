📘 給AutoCAD繪圖工程師的鼓勵

✍ Tiger&蘋果爸 · 2009-06-19

以下文章與大家分享，建議要從事AutoCAD相關產業的朋友可以參考看看!!

文章引用:

人類從事創意或設計工時,最後都將透過繪圖工程師巧手繪製成工程圖說以作為工程施工或機械加工時之依據,可見繪圖工程師之角色極為重要.(除非老闆想節省而自己劃).

依據”職位分類”繪圖工程師工作乙職,係指專門從事<任何工程上專業繪圖作業工作統稱之>,各位從事該工作之網友弟妹们,可千萬別因為職位低階/薪水很低,工作又煩悶,(每天盯著螢幕右手猛抓老鼠滑動=的確很累)眼見同學或同事既不熟悉CAD而從事其它職務,薪水又多好羨慕,千萬別垂頭喪氣.

當你妳看到本篇文章,其時你妳並不孤獨,希望能夠重新調整學習步驟,請依下列各點逐步加強基本功:

A):圖學原理:以前學校學習過的基本功一定(務必)要多複習,由簡而煩,自定 議題自我學習;(如:投影方式/剖面原理/螺旋物件/2個物件相交之交界線或面)

B):AutoCAD熟練度加強

1.除上班外回家應至少應有3個小時以上操作練習(初學者建議星期假日少玩少約會,想要高人一等,可別任為:少年不要留白觀念)

2.只要累計3個月以上(重新)自我磨練要求<不常用指令每個至少玩3次>

3.多蒐集一些操作上可以節省時間的<小秘方>

C):職場專業知識充實

1.有關現職專業知識再加強,如果是建築(土木)行業者,就加強本業相關之專業知至識,其它行業比照辦理.

2.多蒐集別人作品(整套圖)觀察別人繪圖方法與圖面配置佈局,相信一定能夠從中學到不少東西才對.

D):圖面會說話觀念<Excel表格也會說話>

1.本人經常強調<AutoCAD圖面會說話><Excel表格會說話>,試想一下,

<當別人一直再問你妳有關圖面>時,本人認為一定有些地方交待不清楚導致閱讀者無法解析圖面意思.

2.務必很嚴謹地在你妳出圖前反覆檢查,(圖面自主檢查),<零缺點>後再呈交上司審核後出圖.

3.相信你妳只要依循上述幾點,確實執行,你妳在本人心中已經是一位很優秀的<初級繪圖工程師>

E):跨業繪圖:

1.當你妳能夠隨手接案從事其它產業繪圖案件時,你妳將是一位優秀<中級繪圖工程師>

2.想要達成此項目標,平時應多注意其它產業發展並充實該產業專業知識

3.所謂:要想<成功,一定相對要付出時間代價>學習,何況<努力不一定成功,但不努力,一定絕對不會成功的啦!!!!!!>
