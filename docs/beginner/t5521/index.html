Q1.何謂TQC認證？

A1.企業人才技能認證（TQC）是財團法人中華民國電腦技能基金會針對企業用才需求，所提出來的一項整合性認證。這項認證是經過詳細調查、分析各職務工作需求，確認從事該項職務究應具備哪些電腦技能，再對所有電腦技能測驗項目重新歸類整合而成。

Q2. TQC認證考試有分2D、3D嗎？

A2.TQC-CA工程製圖類（CAD Application）有分AutoCAD 2D和AutoCAD 3D兩種考試。

Q3. TQC認證考試可以考哪種版本？

A3. 2007/12/11前，可以考的版本有2000、2002、2004、2005、2006、2008。

Q4. TQC認證考試為何會有進階級和專業級之分，有何分別？

A4.1. 進階級和專業級考的內容不一樣，證書上面會著名考取的是進階級和專業級。

Q5. TQC認證考試是否有倒扣、評分標準為何？

A5.● AutoCAD 2D認證（進階級D2）（只有實作題）：

實作題第一至六類各考一題共六題三十小題(選擇、填充混合)，一二題每大題10分，第三題15分，四、五兩大題各20分，第六題25分，選擇題答錯倒扣該題配分25%，滿分100分(倒扣至零分為止)。於認證時間80分鐘內依題目要求繪圖並求取相關圖元資訊，成績加總達70分（含）以上者該科合格。

● AutoCAD 2D認證（專業級D3）（有分學科及術科）：

本認證分學科及術科兩大部分，總分為100分。學科單、複選混合共20題，每題1分，答錯不倒扣，共20分。實作題第一至六類各考一題共六大題三十小題（選擇、填充混合）一～三題每大題10分，四～五題每大題15分，第六題20分，選擇題答倒扣該題配分25%，共80分，滿分100分（倒扣至零分為止）。於認證時間100分鐘內依題目要求繪圖並求取相關圖元資訊，成績加總達70分（含）以上者該科合格。

● AutoCAD 3D認證（進階級S2）（只有實作題）：

實作題第一至六類各考一題共六題三十小題(選擇、填充混合)，一二題每大題10分，第三題15分，四、五兩大題各20分，第六題25分，選擇題答錯倒扣該題配分25%，滿分100分(倒扣至零分為止)。於認證時間80分鐘內依題目要求繪圖並求取相關圖元資訊，成績加總達70分（含）以上者該科合格。

● AutoCAD 3D認證（專業級S3）（有分學科及術科）：

本認證分學科及術科兩大部分，總分為100分。學科單、複選混合共20題，每題1分，答錯不倒扣，共20分。實作題第一至六類各考一題共六大題三十小題（選擇、填充混合）一～三題每大題10分，四～五題每大題15分，第六題20分，選擇題答倒扣該題配分25%，共80分，滿分100分（倒扣至零分為止）。於認證時間100分鐘內依題目要求繪圖並求取相關圖元資訊，成績加總達70分（含）以上者該科合格。

Q6. TQC認證考試有相關參考書籍或是題庫嗎？

A6.1. TQC認證考試有出版題庫書籍

2. 題庫內直接有學科及術科兩類題目，不能單獨購買。

3. 題庫可以直接至各大書局購買書名分別是「AutoCAD 2008 實力養成暨評量」、「AutoCAD 2006 3D實力養成暨評量」，書名部分只有版本之分，名字是不會變的。

4. 可至 http://www.tqc.org.tw/TQC/press_books.asp 網頁查詢。

Q7.有模擬考題嗎？

A7.1. 購買題庫後，在書籍會有一章節詳述考試流程與考試畫面，請仔細看。

2. 題庫書附光碟內有考試系統軟體，可以自行安裝起來練習。

3. 題庫最後面有附兩份考題，可搭配軟體使用。

Q8.考試會很難嗎，有工作經驗會有幫助嗎？

A8.不會很難，有無工作經驗沒有太大分別。

1. 學科部份可利用空暇的時間，稍加閱讀即可，不一定全都要背下來。

2. 術科只需將認証題庫的習題練熟即可，認証考試內容均從題庫中各大類抽一題，題目內容及尺寸不會有更改，但是答案選項順序不一樣，所以不用背答案。

Q9.報名考試時選專業級還是進階級比較好？

A9.比較建議您考專業級。

1. 普遍業界比較承認專業級證書，因為專業級會考學科，比較不會應徵到那種只會畫圖，不會使用AutoCAD的人。

2. 專業級有分學術科，進階級只有術科，總分都是100分，所以專業級的配分比例較低，比較好考。

Q10.術科考試，是否要標註及設圖層？

A10.考試評分是依照答案評分，不會看你畫的圖，所以有無標註、有無開圖層、有無換顏色、有無改線粗..這些是不會被評分的。

Q11.答案精確度多少？

A11.不同版本的考試有不同的精確度，題庫上有註明的非常清楚。

Q12. AutoCAD 3D物件體積測量有誤差？

A12.1. 據我所知，在其他軟體也會有類似問題，在AutoCAD裡，如果模型作法一樣，只要做布林運算的順序不一樣、CAD版本不同、主機配備不同..體積量測都會不一樣...，何況模型作法不一樣，誤差會更大。

2. AutoCAD 2004以前版本的考試，基本上整數正確即可。

3. AutoCAD 2006版本，在題庫上直接有註明誤差值。

Q13.如何知道最近考試的日期及地點？

A13.請至TQC考生服務網查詢

http://www.itest.org.tw/csfexamonline/default.asp?crttype=TQC&certidtype=student

Q14.可報名對象？

A14.具各類電腦軟體學習經驗的在學學生，或同等學習資歷之社會人士。（就是任何人都可以啦）

Q15.報名日期？

A15.即日起均可報名，想報就報，沒有限時。

Q16.報名方式？

A 16. 1. 一律採用線上報名，請至TQC考生服務網報名

http://www.itest.org.tw/csfexamonline/default.asp?crttype=TQC&certidtype=student

2. 第一次考試者，必須先進入上面的TQC考生服務網網址，點擊「註冊帳號」按鈕，填寫正確的個人資料進行註冊帳號，這樣才可以報名。

3. 如果是已經有考過任何一個TQC認證者，不需重新再註冊，只要用原註冊帳號進入查詢考試時間地點並報名即可。

4. 請注意，報名後必須於考試前14天完成繳費動作，否則視為未報名，不可於考試當天繳費。

Q17.繳費方式？

A17.下面方式自行選一種繳費即可，要注意的是，報名後必須於考試前14天完成繳費動作，否則視未為報名，不可於考試當天繳費。

1. 請至您報名的考場繳費。

2. 使用ATM轉帳：報名後，系統會產生一組繳費帳號，您必須使用提款機將報名費直接轉帳至該帳號，即完成繳費；若遺忘該帳號，請先取消原報名，再重新報名。

3. 請至各區推廣中心繳費。

Q18.如何知道我有報名成功？

A18.1. 繳費成功後，系統會自動寄發「繳費確認通知函」或可自行上考生服務網查詢確認。

2. 應考人可於測驗前七日上網確認考試時間、場次、座號。

Q19.推廣中心地址、電話？

A19.北區 台北市105八德路3段2號6樓 (02) 2577-8806

中區 台中市404北區進化路575號5樓之2 (04) 2238-6572

南區 高雄市813左營區大順一路93號2樓之4 (07) 557-5040

Q20.成績公告時間？

A20.1. 測驗成績將於考後二週後公佈在網站上，考生可自行上網或洽考場查詢。

2. 欲申請複查成績者，可於成績公佈兩週內，向主辦單位申請複查，並隨附複查工本費100元及貼足郵票之回郵信封。

Q21.成績查詢網址？

A21.http://www.tqc.org.tw/TQC/exam_form.asp

Q22.證書何時會發？

A22.本認證各項目達合格標準者，由主辦單位於成績複查後兩週內核發合格證書。

Q23.本認證之考試規則？

A23. 依照相關國家考試規定辦理，發現應考人有下列情形者，一律以零分計算並於網站上公佈：

1. 冒名頂替者。

2. 偽造或變照應考證件者。

3. 以詐術或其他不正當方法，使考試發生不正確之結果者。

Q24.證照不見怎辦？

A24.申請換發人員別證書及補證費用工本費150元。請逕向主辦單位各區推廣中心洽詢。

Q25.我不想考了，可以退費嗎？

A25.本認證受理報名後，不予退費。

Q26.有解答教學嗎？

A26.1.主辦單位發行各項目題庫、特訓教材書籍及動態教學光碟，歡迎至各區推廣中心購買或以劃撥方式購買。

2.至JC-D網站，我自己有整理一些解答

Q27.要帶甚麼去考試阿？

A27.1. TQC的「繳費確認通知函」通知裡面說的很清楚，請注意看

2. 一枝筆

3. 有照片證件

4. 愉快的心

Q28. TQC認證與國際認證的差別？

A28.1. TQC 認證：

此認證是國內業界普遍認定的一個 AutoCAD

認證考試，為私人機構舉辦，還有很多其他類的電腦相關認證，必須自行報名考試，市面上有販售考試題庫，只要購買練習，考試不是問題，詳情可至

http://www.tqc.org.tw/ 查看。

2. 原廠國際受訓結業認證：

原廠授權訓練中心（ATC）課程結束的考試為 "原廠國際受訓結業考試"，與 Autodesk

原廠簽約的受訓中心在受訓完後，經過考試合格才會核發證書，此張證書2D與3D是合在一起的，不會有兩張。

3. Autodesk原廠國際認證：

這是一個新的認證，之前沒有，就像MOS一樣，需要網路線上報名考試，相關考試注意事項可參考 http://blog.yam.com/jcdesign/article/10101543
