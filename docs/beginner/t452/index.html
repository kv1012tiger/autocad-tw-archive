💡 AutoCAD 的小撇步：綜合運用

滑鼠、鎖點、選取到視窗切換，常用組合鍵一次整理

✍ Tiger&蘋果爸 · 2008-09-20

正交平移 物件鎖點 循環選取 修剪延伸切換 視窗切換
① 輔助運用
  • Shift + 滑鼠中間滾輪鍵 → 正交平移（AutoCAD 2006 版本以下，含）
  • Shift + 滑鼠中間滾輪鍵 → 自由環轉（AutoCAD 2007 版本以上）
  • 滑鼠中間滾輪鍵 + Shift → 正交平移（AutoCAD 2007 版本以上）
  • Ctrl + 滑鼠中間滾輪鍵 → 搖桿式平移
  • 「F8」正交模式關閉時及「F10」極座標模式開啟時，在指令作用中可按住 Shift 暫時開啟正交模式
② 物件鎖點運用
  • Ctrl 或 Shift + 滑鼠右鍵 → 顯示鎖點快顯功能表
  • 開啟常駐式鎖點時，物件鎖點作用中可按 Tab 來針對常駐式鎖點設定值進行循環切換
  • 不論物件鎖點是否開啟，都可在指令作用中先按住 Shift 後再按住字母代碼，來開啟物件鎖點暫時取代值。Shift + E → 端點、Shift + C → 中心點
③ 選取運用
  • 選取物件時，可透過按住 Shift → 轉換成移除選取的物件模式
  • 對重疊物件進行選取時，可透過 Ctrl + 滑鼠左鍵 → 進入循環選取模式後，點擊滑鼠左鍵循環選取物件（AutoCAD 2006 版本以下，含）
  • 對重疊物件進行選取時，可透過按住 Shift 後連續敲擊 空白鍵 進行循環選取物件模式，待欲選取物件亮顯後再點擊滑鼠左鍵選取物件（AutoCAD 2007 版本以上）
④ 指令運用
  • 修剪或延伸指令作用中，按住 Shift 可以暫時切換修剪或延伸模式
  • 倒角或圓角指令作用中，不論倒角距離或圓角半徑值為何，都可按住 Shift 暫時將值歸零再進行倒角或圓角
  • 英文說明輸入時，可按住 Ctrl + Shift + U 將英文說明轉換大寫，按住 Ctrl + Shift + L 則是轉換小寫
⑤ AutoCAD 視窗運用
  • 開啟多個 AutoCAD 視窗時，可透過 Ctrl + Tab 快速瀏覽並切換視窗
  • 在配置空間建立多個視埠時，可透過 Ctrl + R 快速瀏覽並切換視埠
  • 在配置空間建立多個配置時，可按住 Ctrl + Page Up 或 Page Down 瀏覽並切換所有標籤（包含模型標籤）
⑥ 瀏覽器視窗運用
  • 開啟多個網頁視窗時，可透過 Ctrl + Tab 快速瀏覽並切換
  • 開啟多個網頁視窗時，可透過 Ctrl + W 逐一關閉
⑦ Windows 視窗運用
  • 開啟多個 Windows 視窗時，可透過 Alt + Tab 快速瀏覽
  • 開啟多個 Windows 視窗時，可透過 Alt + Esc 快速切換
  • 可透過 視窗鍵 + D 快速顯示桌面
  • 若要開啟檔案總管視窗，可透過 視窗鍵 + E
  • 開啟多個檔案總管視窗時，可透過 Ctrl + W 逐一關閉
