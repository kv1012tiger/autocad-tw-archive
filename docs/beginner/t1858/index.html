蘋果爸的投票：大家卡關時都怎麼找答案

✍ Tiger&蘋果爸 · 2009-02-11

投票 解決問題

可以選擇複選方式來票選，選擇上網的朋友請說明上哪一個論壇或是討論區，如奇摩知識+、CAD 相關論壇等等～

蘋果爸的步驟我會先就近找同事討論及找 F1 幫助，不行的話上網搜尋看看，最後再來上 AutoCAD 相關論壇發問！
