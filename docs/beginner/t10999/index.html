📘 『指令別名』與『快捷鍵』

◆指令別名說明：

✍ Tiger&蘋果爸 ·

指令別名說明：

指令別名(精簡指令):您可以用鍵盤輸入指令。有些指令具有縮寫的名稱，稱為指令別名。若要使用鍵盤輸入指令，請在指令行上鍵入完整的指令名稱，然後按下 [Enter] 或空白鍵。有些指令也提供縮寫名稱。例如，您可以不輸入 LINE 啟動 LINE 指令，而是輸入 L。縮寫的指令名稱為指令別名，是在 acad.pgp 檔中定義的。 若要尋找某個指令，您可以在指令行上鍵入一個字母，然後按下 [Tab]，以循環顯示以該字母開始的所有指令。按下 [Enter] 或空白鍵。透過在指令行上按一下滑鼠右鍵，來重新啟動最近使用的指令。

========================================

快捷鍵說明：

您可以為常用指令指定快速鍵 (有時稱為加速鍵)，並可指定暫時取代鍵，以在按下按鍵後執行指令或變更設定。快速鍵是啟動指令的按鍵與按鍵組合。 例如，您可以按下 [Ctrl]+[O] 來開啟檔案，按下 [Ctrl]+[S] 來儲存檔案，這樣與從「檔案」功能表中選擇「開啟」和「儲存」具有相同的結果。

暫時取代鍵是可暫時開啟或關閉在「繪圖設定值」對話方塊中設定的繪圖輔助 (例如，正交模式、物件鎖點或極座標模式) 的按鍵。快速鍵可與指令清單中的任何指令產生關聯。 您可以建立新的快速鍵，也可以修改既有的快速鍵。

[F2] 開啟或關閉文字視窗

[F7] 切換格線模式：GRIDMODE

[F10] 切換極座標追蹤

[F11] 切換物件鎖點追蹤

[F12] 切換動態輸入
