✍ Tiger&蘋果爸 · 2008-08-19

複製文字內容：

將選取來源文字的內容套用到其他文字物件。

說明：

使用「複製文字內容」，您可以將一個文字物件的內容複製至其它文字物件，並且變更其他文字內容。

步驟：

1.輸入CVVTEXT指令，選取來源文字物件(完成複製內容)。

2.選取目的文字物件，可以繼續選取多個目的文字物件，或按 Enter 套用文字內容。

3.按 Enter 或 Esc 結束指令。

教學影片：

https://www.youtube.com/watch?v=lmSW9NBosWA

PS:將LISP程式載入後，複製文字內容 CVVTEXT指令 即變成內建指令，可以再自行定義別名(acad.pgp)，來有效簡化指令輸入，或是自訂工具列按鈕也是一個不錯的選擇。
