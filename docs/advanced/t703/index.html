📘 自訂指令別名(PGP)

您可以不輸入 LINE 啟動 LINE 指令，而是輸入 L。縮寫的指令名稱為…

✍ Tiger&蘋果爸 · 2008-10-14

補充說明：

2006以上版本：

一、「工具」功能表: → 「自訂」→「編輯程式參數」....會以 記事本 來開啟 指令別名定義檔(acad.pgp)

如:

CI, *CIRCLE

CP, *COPY

CC, *COPY

三.新增別名完存檔後關閉 記事本。

四.在指令行輸入 REINIT ，將 PGP檔 打勾案確定，即可使用 CC 別名。

PS:爾後啟動 AutoCAD 時， CC 別名 即變成 常駐式別名。

※注意※

不建議更改原使別名，而且新增別名不能重複，還有請把原始檔(acad.pgp)保留備份，以備不時之需。

2004版本：

「工具」功能表: → 「自訂」→「編輯自訂檔數」→「程式參數」....會以 記事本 來開啟 指令別名定義檔(acad.pgp)

※別名(PGP)檔位置:

C:\Documents and Settings\使用者帳號\Application Data\Autodesk\AutoCAD 版本\版本代號\cht\support\acad.pgp

※搜尋不到pgp檔是因為 cad系統資料夾 是隱藏的請使用以下方法即可找到：

檔案總管 → 工具 → 資料夾選項 → 「檢視」標籤 → 進階設定 →

□ 隱藏已知檔案類型的副檔名 .....把打勾取消

○ 顯示所有檔案及資料夾..........點選選擇
