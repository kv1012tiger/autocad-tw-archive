📘 造型檔概述

相信常常有人收到圖面時，會發生找不到 造型字體檔案 無法開啟，選擇其他SHX…

✍ Tiger&蘋果爸 · 2014-03-04

相信常常有人收到圖面時，會發生找不到 造型字體檔案 無法開啟，選擇其他SHX字型檔也無法替代?

這個 rbtltype.shx 編譯造型檔是使用者自定的造型檔，除非找到來源的建立者不然一定找不到的。

不過還是可以把 AutoCAD 原始的 ltypeshp.shx 編譯造型檔，複製後更名為 rbtltype.shx 編譯造型檔。

關於AutoCAD中文版翻譯 常常會造成許多誤解，像「編譯造型檔」一般並不是使用在字型上，

通常用於「使用者自訂線型」的部份，對於圖面應該沒什麼影響，有可能只影響到「線型(*.lin) 」顯示而已。

註：新版本若沒有 ltypeshp.shx 編譯造型檔，可以使用 COMPILE 指令，將「ltypeshp.shp 原始造型」，編譯成為 ltypeshp.shx 編譯造型檔，然後再使用 LOAD 指令載入。

▲ ltypeshp.shp 原始造型位置:

C:\Program Files\AutoCAD "版本"\Support

--------------------------------------------------

造型檔概述:

造型是一種物件，它的用途與圖塊類似。 您可以先使用 LOAD 指令載入已編譯的含有造型定義的造型檔， 然後，

使用 SHAPE 指令，將該檔案中的造型插入您的圖面。 將造型加入圖面時，您可以指定每一個造型的比例與旋轉量。

AutoCAD SHP 字體是一種特殊類型的造型檔，而且這種字體與造型檔的定義方式相同。

相關指令用途請參考 Auto CAD 2006 說明:

COMPILE 指令

LOAD 指令

SHAPE 指令

資料來源: Auto CAD 2006 說明

---------------------------------------------------

※在早期是被當作類似圖塊的用途，使用 LOAD 指令(類似插入INSERT指令)，載入已編譯的含有造型定義的造型檔。

關於 編譯造型檔 請參考相關回答說明:

[知識]CAD 的造型定義檔與造型字體檔的問題

https://www.autocad-tw.com/t8756-topic

Q1:ltypeshp.shx字型內有多少種造型符號可用?

A1:AutoCAD 本身在 ltypeshp.shx 編譯造型檔 提供了[TRACK1、ZIG、BOX、CIRC1、BAT]五種造型。

Q2:只有這一個檔案嗎？

A2:只有 ltypeshp.shx 編譯造型檔 一個檔案。

Q3:這可以自訂嗎？

A3:可以自訂造型並掛入 ltypeshp.shp 原始造型檔。或是新建 原始造型檔(*.shp)及編譯造型檔(*.shx)。

PS:若只是考量給線型使用，建議請掛入 ltypeshp.shp 原始造型檔。

▼自訂作法請參考以下步驟，請先行備份原始檔案，有問題請再提:

-----------------------------------------------------------------------------

1.在 CAD 先畫好所需要的造型。

2.使用 MKSHAPE 指令 產生原始造型檔(*.shp)及編譯造型檔(*.shx)。

指令: MKSHAPE...選擇 ltypeshp.shp 即可

輸入造型名: A1

輸入分辨率 <128>: 按 Enter 即可

指定插入基準點:

選取物件: 指定對角點: 3 找到

選取物件:按 Enter 即可

正在確定幾何圖形範圍...完成。

正在建立座標列表...完成。

正在格式化座標..-完成。

正在寫新造型...完成。

正在編譯造型/字體描述檔

編譯成功。輸出檔 Z:ProjectAAA.shx含有 126 個位元組。

造型“A1”被創建。

使用 SHAPE 命令在圖中放置造型。
