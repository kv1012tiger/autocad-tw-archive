💻 AutoCAD外掛程式 剪貼簿管理員

AutoCAD可以透過「製作圖塊」WBLOCK指令，及「插入」INSERT指…

✍ Tiger&蘋果爸 · 2012-09-20

AutoCAD可以透過「製作圖塊」WBLOCK指令，及「插入」INSERT指令，達到跨檔案的DWG使用，通常使用者也可以透過「剪貼簿」的「複製」及「貼上」功能滿足，關於如何選用就看個人的工作習慣而定。

但是「剪貼簿」有個小缺點，就是一次只能複製一次使用，現在可以透過 Autodesk Exchange 應用程式網站中，免費提供「剪貼簿管理員」外掛程式，他可以重複使用「剪貼簿」的「複製」功能，並且透過選項板介面管理運用！

功能說明：

1.貼上

2.貼上為圖塊

3.貼到原始座標

4.匯出為DWG圖檔

5.更名

6.移除

註：目前僅支援2012及2013以上版本。
