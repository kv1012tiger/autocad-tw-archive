📘 關於開啟DWG檔案延遲緩慢問題...新增腳本解決方案

😁根據蘋果爸多年使用AutoCAD經驗～

一般開啟新圖時不會延遲，只有開啟某些dwg圖檔會有延遲狀況!!

👇通常會因為以下原因造成延遲👇

狀況1、圖檔使用大量的「多行文字MTEXT」。

狀況2、圖檔使用大量的「Windows字體(標楷體或新細明體)」。

狀況3、開啟了「F12」動態輸入功能。

狀況4、圖檔中有過多錯誤資訊(例如:DGN數據)

狀況5、使用了過多配置。

狀況6、同一張圖使用過多CAD物件(數十萬個物件)。

👇解決辦法👇

辦法1、將不需要排版的MTEXT多行文字炸開成為TEXT單行文字。

辦法2、將Windows字體改為AutoCAD大字體(SHX)。

辦法3、關閉「F12」動態輸入功能。

辦法4、安裝清除錯誤資訊(例如:DGN數據)免費外掛程式，養成隨時清垃圾習慣。

辦法5、使用一檔一配置。

辦法6、將檔案拆成多個小檔，並把過多CAD物件整理(刪除)，原則只留下部分可以判斷正確資訊的物件即可，過多或重複的刪掉。

辦法7、如果是開啟了含有「外部參考」造成延遲，根據官放建議設置以下系統變數。

LAYERNOTIFY = 0

XLOADCTL = 2

INDEXCTL = 3

SAVEFIDELITY = 0

👇其他辦法👇

1.使用Wblock指令將檔案做出去成為新dwg檔。

2.測試電腦不要連網。

3.關閉AutoCAD右上角資訊欄。

4.大型專案或大檔案容量之dwg圖面，可以適時關閉AutoCAD程式(釋放暫存記憶體)，然後重啟AutoCAD程式再開dwg檔。

5.輸入AECTOACAD指令，轉出一張純粹AutoCAD新的dwg檔。

6.開啟 Windows 終極效能 + AutoCAD 即時優先效能。 教學 >> https://youtu.be/rEyil1u13G4 <<

真實案例：

裝況：同一張dwg檔案約有30mb，圖面中CAD物件有831000多個物件。

解決：拆分成4個dwg檔案，對應檔案CAD物件數量 >> 相對應檔案縮小。

表示CAD圖面並無異常，純粹是CAD物件數量太多導致嚴重延遲！

注意：將過多CAD物件整理(重複的刪掉)，原則只留下部分可以判斷正確資訊的物件即可。

再將多行文字分解為單行文字，不使用Windows字體，僅使用AutoCAD大字體(SHX)，不使用多個配置空間，未來作圖一檔一圖一配置，圖面操作會更加流暢。

在擁有記憶體有限的一般普通電腦上，為了確保最佳的性能和效率，可以考慮以下的設置值：

TREEMAX: 保持在一個合理的範圍內，不要設置得太高，以免增加圖形渲染的複雜性。一般來說，可以將其設置在 500 至 1000 之間。

VISRETAIN: 考慮將其設置為 0，以減少檔案大小和渲染負擔。但要注意，這可能會導致在重新打開檔案時需要重新設置圖形可見性。

HIGHLIGHT: 將其設置為 0，以減少圖形渲染的負擔。

REGENMODE: 將其設置為 0，以避免自動重新生成視圖，這樣可以節省系統資源。

MAXACTVP: 將其設置為 1 或 2，以減少同時打開的活動視口數量，從而減少系統負擔。

LAYEREVALCTL: 將其設置為 1，以便在圖層狀態更改時自動重新評估，但要注意這可能會增加一些性能開銷。

LAYOUTREGENCTL: 將其設置為 0，以避免自動重新生成布局視圖，從而節省系統資源。

這些設置的具體值可能會根據你的具體需求和工作流程而有所調整，但在記憶體有限的情況下，這些設置可以幫助減少系統負擔，提高性能和效率。
